# Desktop realism and procedural life: implementation plan

Date: 2026-09-27. Accepted direction; implementation started.

Published release `580936f` includes the canopy runtime through `98556a7`: complete canonical
patches and individual ownership, 5,500 m altitude prefetch, 3,500 m altitude
rendering, water-aware patch reuse, and retained terrain refresh during date
changes. The [integration record](canopy-runtime-integration-2026-09-28.md)
links the immutable RTX 5090 date-seek and flight/walking evidence; the
[deployment receipt](deployment-580936f-2026-09-28.md) records the live build
and byte audit. This does not complete realistic species assets or establish
midrange performance.
Baseline before this work: `27e89c897369270728e5ef4118dcc144e40af7fc`.

This is the current plan for planetary visual quality. It consolidates the
[proposal](desktop-realism-proposal-2026-09-27.md), the
[independent Opus 5.5 review](opus-5.5-desktop-realism-review-2026-09-27.md),
the [review assessment](desktop-realism-assessment-2026-09-27.md), and the
subsequent agreement on procedural trees and instance variation. Those review
records remain historical inputs. This document owns implementation order and
status; dated validation reports own measured results.

## 1. Product target

Desktop realism comes first. Aim for a believable landscape continuously from
orbit through atmospheric descent and low flight to walking. Forests, plants,
rocks and wildlife must exist during approach, with stable identities and
physical dimensions. Landing changes navigation/collision, not world content.
Clear weather must work; clouds cannot be the only way to conceal missing detail.

Quest will receive a separate measured quality profile. Proposed desktop target
is 1440p/60 FPS on a representative midrange gaming PC, with higher settings for
the development RTX 5090. Exact hardware floor and budgets remain open. No
current full-game measurements establish that target.

## 2. Content architecture

### Procedural species

Use the existing biosphere species/lineage identities and dated existence rules.
A species recipe defines trunk taper/curvature, branching rules, crown form,
leaf arrangement, density, bark and foliage palettes, and valid parameter
ranges. Physical allometry relates height, trunk thickness and crown width.
Animal recipes similarly conform to their existing genomes and body plans.

Recipes must describe coherent families. Variation within a species stays
recognizable; different species can have different structures. Habitat controls
distribution through moisture, slope, climate and substrate. Clustering, gaps,
undergrowth and size distribution contribute to realism alongside mesh quality.

Do not introduce a second independent species catalogue inside the renderer.
Current canonical forest candidates have identities and dimensions but are not
yet individually bound to complete dated plant species recipes. That binding is
an explicit future integration task, not something the current forest proves.

### Blender and assetctl

Blender authors detailed reusable components, templates and generation recipes:
trunks, branch structures, roots, foliage clusters, leaf shapes, bark and rock
surfaces, plus compatible animal rigs. Geometry Nodes can produce offline
variants. Exported geometry/material/animation data is usable at runtime;
Blender graphs are not automatically executable browser generators.

Use the repository assetctl boundary. Before expensive generation, validate an
asset brief specifying desktop target, metres, pivots, material/texture and LOD
budgets, visual criteria, provider, provenance and license. Preserve sources and
candidates; use `Assets/_assetctl/` for disposable review output. Export GLB with
matching LODs and appropriate compressed textures. Validate and package with
manifests. Model silhouettes, UVs and deformation quality remain acceptance gates.

### Bounded structural variants

Create/cache a bounded set of structural variants per resident species: different
branch arrangements, crown shapes and age/damage forms. Eight variants is an
initial experiment, not a fixed global budget. Cache keys include species,
recipe/asset version, variant and LOD. Evict by explicit memory budgets.

Assemble compatible modules or generate branch geometry in bounded worker jobs;
cache completed meshes for instancing. Avoid a separate scene object per branch.
Use one resident asset family in the first landscape before scaling to many
species. Structural changes require different cached geometry; recolouring does
not. Matching LODs preserve physical dimensions and crown silhouette.

### Per-instance variation

| Parameter | Representation | Constraint |
| --- | --- | --- |
| Position, yaw and physical size | Instance transform | Owned by canonical individual, camera independent |
| Bark and foliage tints | Separate instance colours with material masks | Shared material, species-constrained palette |
| Crown width, lean and bend | Controlled vertex deformation or compatible morphs | Correct normals, culling bounds, shadows and LOD |
| Bark/leaf surface variation | Atlas selection or texture coordinates | Shared compatible texture/material resources |
| Wind response | Shared field, individual stiffness/phase | Root anchored, bounded date-addressable phase |
| Seasonal appearance | Species/environment/date parameters | Respect lifecycle and signed BigInt time |

Colour/shape variation should not require a unique material for every tree.
Instancing reduces submissions, not vertex, fragment, overdraw or shadow costs.
Many topology variants and materials can still fragment batches. Measure the
tradeoff between diversity, cache size and rendering cost.

## 3. Identity, time and physical scale

- Preserve current seed/body/cell identities, positions, heights and yaw during
  the initial renderer work. A new placement distribution requires an explicit
  population version and compatibility decision.
- Derive species recipes from species identity; structural variant and
  individual parameters from stable individual identity. Camera, cache contents,
  task completion order and visit order must never choose these values.
- Distinguish identity versions (world/population/history) from appearance
  versions (assets/material/representation). Pixel baseline keys include both.
- A future growth/generation index must respect species birth/extinction and
  body lifecycle. Use bounded random-access queries for dates; do not simulate
  all preceding time. Handle negative dates with deliberate floor/modulo rules.
- Roots remain at canonical ground contact. Species dimensions constrain mesh
  scale, collision proxies, culling bounds and canopy summaries.
- Fix or explain existing history/version compatibility failures before adding
  new identity version axes. Renderer-only changes do not silently reseed worlds.

## 4. Continuous forest and terrain representations

| Scale | Intended representation |
| --- | --- |
| Near | Detailed branches, leaves, trunks, ground cover and contact shadows |
| Middle | Simpler meshes or relightable impostors preserving individual form |
| Far | Aggregate canopy preserving crown coverage, height and colour |
| Regional/orbital | Terrain/canopy appearance derived from the same ecological field |

Initially derive aggregate coverage from the existing population rules and
bounded regional summaries. Do not invent dense far forests that resolve into
sparse near trees. Avoid drawing both representations at full coverage during
handoff. Treat ground and canopy height separately; trees must not become solid
collision terrain. Evaluate parallax, lighting and silhouettes in clear weather.

Use projected size/error and hysteresis for LOD, with physical distance and
memory limits. Forward prefetch may prioritize work but cannot move the visible
dense forest area when the camera rotates. Resident regions use stable origins
and retained instance buffers. Change only dirty instance ranges. Later spatial
chunking must handle both view visibility and off-camera shadow casters.

Existing terrain already supplies adaptive tiles, horizon culling and local
surface detail. Improve rock/soil/wetness material response and metre-scale
features without adding an unversioned terrain height field. GPU grass patches
are a candidate for dense cover; occupancy remains consistent with the world
query and tile height data.

## 5. Lighting, atmosphere, clouds and frame budget

Establish a common sun/sky, aerial perspective and exposure contract across
terrain, trees, fauna, water and clouds. Terrain already uses PBR; current tree
and animal materials are simpler. Evaluate foliage transmission and coherent
roughness/normal detail under the common lighting baseline.

Audit the RGBA16F cloud scene capture, which currently has no requested MSAA.
Compare bounded MSAA/depth-resolve and post-AA approaches before choosing leaf
coverage techniques. Any shader deformation must be reflected in shadow/depth
passes. Logarithmic depth is enabled; measure its cost before changing depth
architecture. Keep current full-resolution desktop clouds as the baseline while
investigating the earlier reduced-resolution checker artifact.

Start with one bounded local sun-shadow region, then evaluate cascades and far
terrain shadow approximations. A shared atmosphere LUT implementation is a
candidate follow-on, not a prerequisite for all useful improvements. Stay on
WebGL2 until a measured bottleneck warrants an independently scoped migration.

Measure full-game CPU, GPU, uploads, draws, triangles, JS heap and estimated GPU
memory. Track distributions and cold/warm streaming separately. Reserve costs
for terrain, vegetation, fauna, water, shadows, clouds, UI and headroom. Existing
416 MiB accounting is incomplete driver/browser accounting, not a certified
desktop asset budget. Expand budgets deliberately with measurements.

## 6. Animal realism

Start with one continuous, rigged body plan compatible with existing genome
proportions, then expand. Bind bone lengths/morphs to the genome; authored rigs
must support realistic deformation. Keep exact-date movement and individual IDs.
Investigate deterministic paths with bounded segment/corridor obstacle checks,
stable interval boundaries and fallbacks. Foot contact requires reach limits,
ground normals and stance timing, not merely body-height adjustment.

Profile conventional skinning before adopting instanced bone palettes or baked
vertex animation. Keep the current 128-animal budget until evidence supports
more. Structural diversity must not come from disconnected anatomy.

# Desktop surface lighting

Implemented and checked in the actual desktop game; final realism and performance
acceptance remain open.
The current deployed build is still `8e16776`.

The normal planet panel now offers **Surface lighting: detailed/basic**. The
choice persists in the URL (`lighting=0` selects basic). Detailed lighting uses
the existing dated stellar sun, ACES exposure, and planetary spin compensation.
An atmospheric hemisphere fill reduces the existing ambient contribution while
adding directional sky and ground light. Fill fades toward orbit and night;
airless worlds receive no atmospheric fill. XR keeps the prior lighting profile.

One 2048² PCF shadow map covers a 320 m square around the observer's ground
projection. Its 1,000 m depth interval and 6 cm normal bias scale with renderer
units. The target snaps to a planet-relative texel grid, preserving its phase
when the renderer rebases. Shadow strength fades between 300 and 700 m altitude
and around sunset. This is a bounded local shadow region, not planetary terrain
occlusion or cascaded shadows. Lateral map-edge transitions still need visual
assessment.

The shadow target adds an estimated 32 MiB for packed depth colour and a depth
attachment at 2048², outside the existing terrain/cloud reserves. It remains
allocated when basic lighting is selected, avoiding reallocation on toggles.
Diagnostics report this estimate separately; driver overhead is not included.

Terrain, nearby legacy/detailed trees, ground flora and instanced fauna cast and
receive shadows. Terrain depth uses the same morph and edge-lock expressions as
its colour pass. Legacy tree depth uses the same canonical coverage mask as its
colour pass, including hidden slots replaced by detailed assets. Detailed trees
retain their existing wind and leaf-alpha depth hooks. The distant census canopy
does not cast local shadows.

The local sun frustum participates in terrain and life retention, so turning
away from a nearby caster does not automatically erase its shadow. Terrain's
standard camera culling uses bounds enclosing both morph endpoints. The same
bounded forest/life instance capacities apply, but retaining off-camera casters
can add CPU work and vertex submissions; a small map alone does not eliminate
those costs. Near/mid tree batches still submit their retained instances to the
shadow pass and clip outside the volume.

The main scene updates the shadow map once per frame, including when clouds
capture that scene. Lake reflections reuse the previous map. Profile scene GPU
times include shadow work; they are not separate shadow-pass measurements.

## What the local path does

The forest can asynchronously load a supplied two-LOD tree asset family into

import * as THREE from 'three';

export const SURFACE_SHADOW = {widthM:320, depthM:1000, mapSize:2048, normalBiasM:.06} as const;
export type SurfaceLightingFrame = {
  planet:THREE.Object3D; radiusM:number; eye:THREE.Vector3; sun:THREE.Vector3;
  altitudeM:number; atmosphere:boolean; enabled:boolean; immersive:boolean;
};

/** One local desktop shadow region. All dimensions are physical metres, even
 * while the renderer changes units during descent. It changes presentation,
 * never terrain sampling, canonical populations or the simulated clock. */
export class SurfaceLighting {
  readonly sky=new THREE.HemisphereLight('#b5cce3','#697451',0);
  readonly localFrustum=new THREE.Frustum();
  private up=new THREE.Vector3(); private center=new THREE.Vector3();
  private right=new THREE.Vector3(); private vertical=new THREE.Vector3();
  private axis=new THREE.Vector3(); private matrix=new THREE.Matrix4();
  private scale=new THREE.Vector3(); private anchor=new THREE.Vector3();
  private baselineAmbient:number;
  private active=false; private unitsPerM=1; private altitudeM=Infinity;
  readonly sun:THREE.DirectionalLight;
  private ambient:THREE.AmbientLight;
  constructor(sun:THREE.DirectionalLight,ambient:THREE.AmbientLight){
    this.sun=sun;this.ambient=ambient;
    this.baselineAmbient=ambient.intensity;
    sun.shadow.mapSize.setScalar(SURFACE_SHADOW.mapSize);
    sun.shadow.bias=-.000025;
    sun.shadow.camera.up.set(0,1,0);
    this.sky.name='Local atmospheric sky and ground fill';
  }
  disable(){
    this.active=false;this.sun.castShadow=false;this.sun.shadow.intensity=0;
    this.sky.intensity=0;this.ambient.intensity=this.baselineAmbient;
  }
  update(frame:SurfaceLightingFrame):THREE.Frustum|null{
    const {planet,radiusM,eye,sun,altitudeM,enabled,immersive,atmosphere}=frame;
    this.disable();this.altitudeM=altitudeM;
    this.unitsPerM=this.scale.setFromMatrixScale(planet.matrixWorld).x/radiusM;
    if(!enabled||immersive||!Number.isFinite(altitudeM)||!Number.isFinite(this.unitsPerM)||this.unitsPerM<=0)return null;
    this.up.copy(eye).applyMatrix4(this.matrix.copy(planet.matrixWorld).invert()).normalize().transformDirection(planet.matrixWorld);
    const day=THREE.MathUtils.smoothstep(this.up.dot(sun),-.08,.2);
    const close=1-THREE.MathUtils.smoothstep(altitudeM,2500,6000);
    const fill=atmosphere&&this.sun.intensity>0?day*close:0;
    this.sky.position.copy(this.up);
    this.sky.intensity=.7*fill*Math.min(4,Math.max(0,this.sun.intensity)/3);
    this.ambient.intensity=this.baselineAmbient*(1-.6*fill);
    const strength=day*(1-THREE.MathUtils.smoothstep(altitudeM,300,700));
    if(strength<=0||this.sun.intensity<=0)return null;
    const unit=this.unitsPerM,half=SURFACE_SHADOW.widthM*.5*unit;
    this.center.copy(eye).addScaledVector(this.up,-altitudeM*unit);
    // Snap relative to the planet centre, not the rebased renderer origin.
    // Translating the scene therefore cannot change the shadow texel phase.
    this.anchor.setFromMatrixPosition(planet.matrixWorld);
    this.axis.set(0,1,0);if(Math.abs(sun.y)>.98)this.axis.set(1,0,0);
    this.right.crossVectors(this.axis,sun).normalize();
    this.vertical.crossVectors(sun,this.right).normalize();
    this.sun.shadow.camera.up.copy(this.vertical);
    const texel=2*half/SURFACE_SHADOW.mapSize;
    this.scale.copy(this.center).sub(this.anchor);
    const x=this.scale.dot(this.right),y=this.scale.dot(this.vertical);
    this.center.addScaledVector(this.right,Math.round(x/texel)*texel-x)
      .addScaledVector(this.vertical,Math.round(y/texel)*texel-y);
    this.sun.target.position.copy(this.center);
    this.sun.position.copy(this.center).addScaledVector(sun,SURFACE_SHADOW.depthM*.5*unit);
    this.sun.target.updateMatrixWorld();this.sun.updateMatrixWorld();
    const camera=this.sun.shadow.camera;
    camera.left=-half;camera.right=half;camera.bottom=-half;camera.top=half;
    camera.near=.1*unit;camera.far=SURFACE_SHADOW.depthM*unit;camera.updateProjectionMatrix();
    this.sun.shadow.normalBias=SURFACE_SHADOW.normalBiasM*unit;
    this.sun.shadow.intensity=strength;this.sun.castShadow=true;
    this.sun.shadow.updateMatrices(this.sun);
    this.localFrustum.setFromProjectionMatrix(this.matrix.multiplyMatrices(camera.projectionMatrix,camera.matrixWorldInverse).multiply(planet.matrixWorld));
    this.active=true;return this.localFrustum;
  }
  diagnostics(){return {active:this.active,altitudeM:this.altitudeM,unitsPerM:this.unitsPerM,
    widthM:SURFACE_SHADOW.widthM,depthM:SURFACE_SHADOW.depthM,mapSize:SURFACE_SHADOW.mapSize,
    shadowIntensity:this.sun.shadow.intensity,skyIntensity:this.sky.intensity,ambientIntensity:this.ambient.intensity,
    allocated:!!this.sun.shadow.map,
    // RGBA8 packed depth plus a conservative four-byte depth attachment.
    // Driver overhead is not included; the map is retained while basic is on.
    estimatedTargetBytes:this.sun.shadow.map?this.sun.shadow.map.width*this.sun.shadow.map.height*8:0};}
}

    prior.call(this,shader,renderer);

    shader.vertexShader=shader.vertexShader.replace('#include <begin_vertex>','#include <begin_vertex>\nvForestCoverage=instanceCoverage;vForestSeed=instanceForestSeed;');
    shader.fragmentShader='flat varying float vForestCoverage,vForestSeed;\n'+forestCoverageGLSL+shader.fragmentShader;

/** Preserve the ordinary camera-visible ordering before allocating spare
 * instance capacity to off-camera casters. All scratch arrays are retained. */
export function floraShadowOrder(candidates:Candidates,visibleCount:number,shadow:Frustum|null,origin:Vector3,
  order:Uint32Array,seen:Uint8Array,sphere:Sphere){
  let count=0;seen.fill(0,0,candidates.count);
  for(let slot=0;slot<visibleCount;slot++){
    const index=candidates.survivorIndex(slot);order[count++]=index;seen[index]=1;
  }
  if(shadow)for(let index=0;index<candidates.count;index++){
    if(seen[index])continue;
    sphere.center.set(candidates.centerX[index],candidates.centerY[index],candidates.centerZ[index]).add(origin);
    sphere.radius=candidates.radius[index];
    if(shadow.intersectsSphere(sphere))order[count++]=index;
  }
  return count;
}

/** Experimental CPU-built mip chain for a 4x4 Atlas foliage texture atlas.
 * The GLB image and level-zero pixels are never changed. This helper is opt-in,
 * performs its CPU work synchronously, and does not change alpha hash/A2C or
 * custom depth/distance material policy. Cells are filtered independently
 * while each has texels; smaller tail levels can preserve only global coverage. */
export const TREE_FOLIAGE_MIPS_VERSION='tree-foliage-coverage-mips-1';
export const TREE_FOLIAGE_ALPHA_CUTOFF=.5;
export const TREE_FOLIAGE_ATLAS_COLUMNS=4;
export const TREE_FOLIAGE_ATLAS_ROWS=4;
const LINEAR_SRGB=Float32Array.from({length:256},(_,byte)=>{
	const c=byte/255;return c<=.04045?c/12.92:((c+.055)/1.055)**2.4;
});
const INSTALLED=new WeakMap<Texture,InstalledTreeFoliageMipChain>();

export type TreeFoliageMipOptions={alphaCutoff?:number;cellColumns?:number;cellRows?:number};
export type TreeFoliageMipPixels={width:number;height:number;data:Uint8ClampedArray};
export type TreeFoliageMipLevelReport={
  level:number;width:number;height:number;mode:'per-cell'|'global-tail';
  targetCoverage:number;coverage:number;coverageError:number;perCellCoverage:(number|null)[];
};
export type TreeFoliageMipPixelChain={levels:TreeFoliageMipPixels[];report:TreeFoliageMipLevelReport[];
  baseCoverage:number;baseCellCoverage:number[];cellGrid:[number,number];alphaCutoff:number};
export type InstalledTreeFoliageMipChain={report:TreeFoliageMipLevelReport[];baseCoverage:number;baseCellCoverage:number[];
  cellGrid:[number,number];alphaCutoff:number;dispose():void};

function assertOptions(width:number,height:number,options:TreeFoliageMipOptions){
  const columns=options.cellColumns??TREE_FOLIAGE_ATLAS_COLUMNS,rows=options.cellRows??TREE_FOLIAGE_ATLAS_ROWS;
  const cutoff=options.alphaCutoff??TREE_FOLIAGE_ALPHA_CUTOFF;
  if(!Number.isSafeInteger(width)||!Number.isSafeInteger(height)||width!==height||width<4||
    (width&(width-1))!==0||width%columns!==0||height%rows!==0||
    !Number.isInteger(columns)||!Number.isInteger(rows)||columns<1||rows<1||
    !Number.isFinite(cutoff)||cutoff<=0||cutoff>=1)
    throw new Error('Foliage mip input must be a square power-of-two 4x4-cell atlas with cutoff in (0,1)');
  return {columns,rows,cutoff};
}
function checkPixels(width:number,height:number,data:Uint8Array|Uint8ClampedArray){
	if(!(data instanceof Uint8Array)&&!(data instanceof Uint8ClampedArray)||data.length!==width*height*4)throw new Error('Foliage mip pixels must be RGBA8');
}
function linearToSrgbByte(value:number){
  const c=Math.max(0,Math.min(1,value));const encoded=c<=.0031308?12.92*c:1.055*c**(1/2.4)-.055;
  return Math.max(0,Math.min(255,Math.round(encoded*255)));
}
function coverage(data:Uint8ClampedArray,width:number,height:number,x0=0,y0=0,regionWidth=width,regionHeight=height,cutoffByte=128){
  let count=0;for(let y=y0;y<y0+regionHeight;y++)for(let x=x0;x<x0+regionWidth;x++)if(data[(y*width+x)*4+3]!>=cutoffByte)count++;
  return count/(regionWidth*regionHeight);
}
function remapAlpha(source:Uint8ClampedArray,destination:Uint8ClampedArray,width:number,x0:number,y0:number,w:number,h:number,target:number,cutoffByte:number){
  const histogram=new Uint32Array(256),length=w*h;
  for(let y=y0;y<y0+h;y++)for(let x=x0;x<x0+w;x++)histogram[source[(y*width+x)*4+3]!]++;
	const targetCount=target*length;let cumulative=0,bestBin=0,bestCount=0,bestError=Infinity;
  for(let bin=255;bin>=1;bin--){
    cumulative+=histogram[bin]!;
    const error=Math.abs(cumulative-targetCount);
    // Prefer undercoverage on an exact tie so correction never grows the
    // silhouette when this small cell cannot represent its base fraction.
    if(error<bestError||(error===bestError&&cumulative<bestCount)){bestError=error;bestCount=cumulative;bestBin=bin;}
  }
	// A tiny upward bias avoids floating-point products just below x.5, which
	// round down and can move the selected histogram bin back under the cutoff.
	const scale=bestCount===0?(cutoffByte-1)/255:((cutoffByte-.5)/bestBin)+1e-7;
  for(let y=y0;y<y0+h;y++)for(let x=x0;x<x0+w;x++){
    const p=(y*width+x)*4,a=source[p+3]!;
    destination[p+3]=Math.max(0,Math.min(255,Math.round(a*scale)));
  }
}
function downsampleRegion(source:Uint8ClampedArray,srcWidth:number,srcHeight:number,destination:Uint8ClampedArray,dstWidth:number,
  x0:number,y0:number,dstRegionWidth:number,dstRegionHeight:number){
  for(let y=0;y<dstRegionHeight;y++)for(let x=0;x<dstRegionWidth;x++){
    const sx=(x0+x)*2,sy=(y0+y)*2,out=((y0+y)*dstWidth+x0+x)*4;
    let alpha=0,pr=0,pg=0,pb=0,ur=0,ug=0,ub=0;
    for(let dy=0;dy<2;dy++)for(let dx=0;dx<2;dx++){
      const p=((sy+dy)*srcWidth+sx+dx)*4,a=source[p+3]!/255;
		const r=LINEAR_SRGB[source[p]!]!,g=LINEAR_SRGB[source[p+1]!]!,b=LINEAR_SRGB[source[p+2]!]!;
      alpha+=a;pr+=r*a;pg+=g*a;pb+=b*a;ur+=r;ug+=g;ub+=b;
    }
    alpha*=.25;const divisor=alpha>0?alpha*4:4;
    destination[out]=linearToSrgbByte(alpha>0?pr/(alpha*4):ur/divisor);
    destination[out+1]=linearToSrgbByte(alpha>0?pg/(alpha*4):ug/divisor);
    destination[out+2]=linearToSrgbByte(alpha>0?pb/(alpha*4):ub/divisor);
    destination[out+3]=Math.round(alpha*255);
  }
}

/** Build an explicit chain from decoded sRGB RGBA pixels. Each atlas cell is
 * downsampled independently while it still occupies at least one texel.
 * Smaller tail levels necessarily combine cells and preserve only atlas-wide
 * coverage. Source pixels are copied and never mutated. */
export function buildTreeFoliageMipPixels(width:number,height:number,rgba:Uint8Array|Uint8ClampedArray,
  options:TreeFoliageMipOptions={}):TreeFoliageMipPixelChain{
  const {columns,rows,cutoff}=assertOptions(width,height,options);checkPixels(width,height,rgba);
  const source=new Uint8ClampedArray(rgba),levels:TreeFoliageMipPixels[]=[{width,height,data:new Uint8ClampedArray(source)}];
  const cutoffByte=Math.ceil(cutoff*255),baseCoverage=coverage(source,width,height,0,0,width,height,cutoffByte);
  const cellWidth=width/columns,cellHeight=height/rows,baseCellCoverage:number[]=[];
  for(let cy=0;cy<rows;cy++)for(let cx=0;cx<columns;cx++)baseCellCoverage.push(coverage(source,width,height,cx*cellWidth,cy*cellHeight,cellWidth,cellHeight,cutoffByte));
  const report:TreeFoliageMipLevelReport[]=[{level:0,width,height,mode:'per-cell',targetCoverage:baseCoverage,coverage:baseCoverage,coverageError:0,
    perCellCoverage:baseCellCoverage.slice()}];
  let filterSource=source,srcWidth=width,srcHeight=height,level=0;
  while(srcWidth>1||srcHeight>1){
    const dstWidth=Math.max(1,srcWidth>>1),dstHeight=Math.max(1,srcHeight>>1),filtered=new Uint8ClampedArray(dstWidth*dstHeight*4);
    const perCell=dstWidth>=columns&&dstHeight>=rows;
    if(perCell){
      const dstCellWidth=dstWidth/columns,dstCellHeight=dstHeight/rows,srcCellWidth=srcWidth/columns,srcCellHeight=srcHeight/rows;
      for(let cy=0;cy<rows;cy++)for(let cx=0;cx<columns;cx++){
        const x=cx*dstCellWidth,y=cy*dstCellHeight;
        downsampleRegion(filterSource,srcWidth,srcHeight,filtered,dstWidth,x,y,dstCellWidth,dstCellHeight);
      }
      // Continue filtering the uncorrected averaged alpha; coverage remapping
      // changes only the uploaded copy and cannot bias later RGB mips.
      const uploaded=new Uint8ClampedArray(filtered),cellCoverage:number[]=[];
      for(let cy=0;cy<rows;cy++)for(let cx=0;cx<columns;cx++){
        const x=cx*dstCellWidth,y=cy*dstCellHeight,target=baseCellCoverage[cy*columns+cx]!;
        remapAlpha(filtered,uploaded,dstWidth,x,y,dstCellWidth,dstCellHeight,target,cutoffByte);
        cellCoverage.push(coverage(uploaded,dstWidth,dstHeight,x,y,dstCellWidth,dstCellHeight,cutoffByte));
      }
      levels.push({width:dstWidth,height:dstHeight,data:uploaded});
      const current=coverage(uploaded,dstWidth,dstHeight,0,0,dstWidth,dstHeight,cutoffByte);
      report.push({level:++level,width:dstWidth,height:dstHeight,mode:'per-cell',targetCoverage:baseCoverage,coverage:current,
        coverageError:current-baseCoverage,perCellCoverage:cellCoverage});
    }else{
      downsampleRegion(filterSource,srcWidth,srcHeight,filtered,dstWidth,0,0,dstWidth,dstHeight);
      const uploaded=new Uint8ClampedArray(filtered);
      remapAlpha(filtered,uploaded,dstWidth,0,0,dstWidth,dstHeight,baseCoverage,cutoffByte);
      levels.push({width:dstWidth,height:dstHeight,data:uploaded});
      const current=coverage(uploaded,dstWidth,dstHeight,0,0,dstWidth,dstHeight,cutoffByte);
      report.push({level:++level,width:dstWidth,height:dstHeight,mode:'global-tail',targetCoverage:baseCoverage,coverage:current,
        coverageError:current-baseCoverage,perCellCoverage:Array(columns*rows).fill(null)});
    }
    filterSource=filtered;srcWidth=dstWidth;srcHeight=dstHeight;
  }
  return {levels,report,baseCoverage,baseCellCoverage,cellGrid:[columns,rows],alphaCutoff:cutoff};
}

/** Install regular Texture mip image sources without cloning its decoded GLB
 * image or texture. LODs, colour/depth/distance passes can continue sharing the
 * same map. The caller must ensure all users agree on this texture's mip policy.
 * Call the returned dispose() when the owning tree family is released. */
export async function installTreeFoliageCoverageMipmaps(texture:Texture,options:TreeFoliageMipOptions={}):Promise<InstalledTreeFoliageMipChain>{
	if(INSTALLED.has(texture))throw new Error('Coverage-preserving foliage mipmaps are already installed on this texture');
	const image=texture.image as CanvasImageSource|undefined;if(!image)throw new Error('Foliage texture has no decoded image');
	const {width,height}=dimensions(image);assertOptions(width,height,options);
	const canvas=makeCanvas(width,height),ctx=context2D(canvas),generated:CanvasMip[]=[];
  try{
    ctx.drawImage(image,0,0,width,height);
    const pixels=ctx.getImageData(0,0,width,height).data;
    const chain=buildTreeFoliageMipPixels(width,height,pixels,options),mipmaps:CanvasImageSource[]=[image];
		for(let i=1;i<chain.levels.length;i++){
			const level=chain.levels[i]!,levelCanvas=makeCanvas(level.width,level.height);generated.push(levelCanvas);
			const levelContext=context2D(levelCanvas);
			const imageData=levelContext.createImageData(level.width,level.height);imageData.data.set(level.data);levelContext.putImageData(imageData,0,0);
			mipmaps.push(levelCanvas);
    }
    const oldMipmaps=texture.mipmaps,oldGenerateMipmaps=texture.generateMipmaps;
    texture.mipmaps=mipmaps as unknown as typeof texture.mipmaps;texture.generateMipmaps=false;texture.needsUpdate=true;
    let disposed=false;
		const installed:InstalledTreeFoliageMipChain={report:chain.report,baseCoverage:chain.baseCoverage,baseCellCoverage:chain.baseCellCoverage,cellGrid:chain.cellGrid,alphaCutoff:chain.alphaCutoff,
			dispose(){
				if(disposed)return;disposed=true;
				if(texture.mipmaps===mipmaps){texture.mipmaps=oldMipmaps;texture.generateMipmaps=oldGenerateMipmaps;texture.needsUpdate=true;}
				if(INSTALLED.get(texture)===installed)INSTALLED.delete(texture);
				for(const item of generated){item.width=0;item.height=0;}
			}};
		INSTALLED.set(texture,installed);return installed;
  }catch(error){
    for(const item of generated){item.width=0;item.height=0;}
    throw error;
  }finally{canvas.width=0;canvas.height=0;}
}

  private reconcileBatch(batch:number){

/** Selection estimates use the already resident lattice. Calling the complete
 * procedural geology twice for every leaf and parent stalled contact frames.
 * Collision continues to use the actual settled mesh and authoritative field. */
function patchHeightAt(patch:Patch,d:V3){
  const t=patch.tile,[x,y,z]=d,a=Math.max(1e-12,Math.abs(d[Math.floor(t.face/2)]));
  const [u,v]=[[-z/a,y/a],[z/a,y/a],[x/a,-z/a],[x/a,z/a],[x/a,y/a],[-x/a,y/a]][t.face];
  const n=2**t.level,stride=PATCH_SEGMENTS+1;
  const px=Math.max(0,Math.min(PATCH_SEGMENTS,((u+1)*.5*n-t.x)*PATCH_SEGMENTS));
  const py=Math.max(0,Math.min(PATCH_SEGMENTS,((v+1)*.5*n-t.y)*PATCH_SEGMENTS));
  const ix=Math.min(PATCH_SEGMENTS-1,Math.floor(px)),iy=Math.min(PATCH_SEGMENTS-1,Math.floor(py)),fx=px-ix,fy=py-iy,h=patch.data.surfaceHeight;
  return (h[iy*stride+ix]*(1-fx)+h[iy*stride+ix+1]*fx)*(1-fy)
    +(h[(iy+1)*stride+ix]*(1-fx)+h[(iy+1)*stride+ix+1]*fx)*fy;
}

// A tile's baked sea level is quantized to this many metres so scrubbing the
// date cannot thrash the streaming queue: within one bucket every tile
// (fresh or resident) is built at the exact same snapped `waterLevelM`
// (bit-identical, not merely "close"), so two tiles sharing a bucket can
// never disagree at their shared edge — the seam hazard this task's brief
// calls out is eliminated by construction, not by tolerance. Justification
// for 25 m specifically (measured 2026-09-18, see the task report for the
// full numbers): for a representative ocean-bearing body (median of 830
// sampled oceanNs->giantNs intervals in the LETHRA-001 corpus) water moves
// only ~0.6 m/s of real time at the 'historical' playback tier (the tier
// actually meant for watching shoreline change) -- ~40 real seconds between
// bucket crossings there, so normal playback never thrashes. At the far
// faster 'geological' tier it moves ~627 m/s (~1 bucket every ~40 ms, a few
// per frame at 60 fps); that repeatedly re-marks the current leaf set stale,
// but the existing per-frame worker-admission cap below (independent of this
// bucket size) already bounds how many tiles can start in any one frame, so
// a fast crossing cannot stall a frame -- it just keeps the async queue
// continuously busy while the user is deliberately watching fast-forward
// geological change, which is the correct behaviour. Across the full 8,000 m
// authored range (`stellar-evolution.ts`'s `waterKeysFor`) this gives 320
// distinguishable steps, far finer than the ~24 percentage-point ocean-area
// swing already measured between t=0 and CATALOGUE_EPOCH_NS, so ordinary
// navigation reads as continuous, not steppy.
const WATER_LEVEL_BUCKET_M = 25;

// A software rasteriser (SwiftShader/llvmpipe, the default for headless
// Playwright/CI runs) does its rendering work on the same main thread that
// must also upload/compile every completed tile, so it is already CPU-bound
// per frame; widening the worker pool there only bursts more upload/compile
// work into that same thread and measurably *hurts* landing time. Detect it
// once via the standard WEBGL_debug_renderer_info string and keep the
// original single-worker throughput there; real GPUs get the wider pool.
let softwareRendererCache: boolean | null = null;
function isSoftwareRenderer(): boolean {
  if (softwareRendererCache !== null) return softwareRendererCache;
  try {
    const canvas = typeof document !== 'undefined' ? document.createElement('canvas') : null;
    const gl = canvas?.getContext('webgl2') || canvas?.getContext('webgl');
    const info = gl?.getExtension('WEBGL_debug_renderer_info');
    const renderer = info ? String(gl!.getParameter(info.UNMASKED_RENDERER_WEBGL)) : String(gl?.getParameter(gl.RENDERER) ?? '');
    softwareRendererCache = /swiftshader|llvmpipe|software|basic render/i.test(renderer);
  } catch { softwareRendererCache = false; }
  return softwareRendererCache;
}

/**
 * A conservative bounding THREE.Sphere (unit-sphere, chord-distance units --
 * NOT metres, see `needsFineContact`'s own doc) around a RiverRegion's 4
 * corners plus its centre, in the same local-tangent-plane construction the
 * constructor already used inline for `body.hydrology` alone. Shared here so
 * `waterRegion` (the single legacy hydrology region) and every
 * `body.canonicalRivers` entry (the multi-region registry, gating
 * `needsFineContact` below) are built by one identical implementation.
 */
function riverRegionSphere(r: RiverRegion): THREE.Sphere {
  const b=[r.boundsM[0],r.boundsM[1],r.boundsM[2],r.boundsM[3]],points:[[number,number],[number,number],[number,number],[number,number],[number,number]]=[[b[0],b[1]],[b[0],b[3]],[b[2],b[1]],[b[2],b[3]],[(b[0]+b[2])/2,(b[1]+b[3])/2]],direction=([x,z]:[number,number])=>new THREE.Vector3(...r.origin).addScaledVector(new THREE.Vector3(...r.east),x/r.radiusM).addScaledVector(new THREE.Vector3(...r.north),z/r.radiusM).normalize();
  const directions=points.map(direction),center=directions.reduce((sum,p)=>sum.add(p),new THREE.Vector3()).normalize(),radius=Math.max(...directions.map(p=>p.distanceTo(center)));
  return new THREE.Sphere(center,radius);
}

  // starving fine-tile demand/supply across the entire fineContactLevel grid

  // hysteresis numbers and the exact single-cache-per-frame contract that
  // keeps demand (`contactPatches`) and supply (`finePriority`/split target/
  // `diagnostics()`) from ever gating on different booleans.
  //
  // Distance measure: `riverFeatureAt` (river-sample.ts), evaluated directly
  // against `body.hydrology` plus every `body.canonicalRivers` entry -- NOT

  // spheres were ~20,021-20,435 m in radius against a 200/260 m threshold,

  private static readonly FINE_CONTACT_CACHE_MOVE_M = 5;
  private fineContactActive = false;

  private readonly fineContactCachePoint = new THREE.Vector3(Infinity, Infinity, Infinity);
  /**
   * Single source of truth for "is fine (sub-metre) contact precision
   * warranted right now" -- true iff `hasHydrology` AND the current contact
   * point (`this.contactFocus`, kept in lockstep with the exact point
   * `contactPatches()` is called with by both the walking and landing flows
   * in main.ts -- setContactFocus is always called with that same value
   * immediately before/around it) is within `FINE_CONTACT_ENGAGE_M` (outward,
   * wet-edge metres -- see `riverFeatureAt`'s own doc) of any hydrology
   * region (or, once engaged, stays true out to `FINE_CONTACT_DISENGAGE_M`
   * -- the hysteresis band above). Cached and recomputed only when the
   * point has moved more than `FINE_CONTACT_CACHE_MOVE_M`, so every call
   * site within the same frame (`finePriority`, the quadtree split target,
   * `contactPatches`'s level/offsets, `diagnostics()`) reads the exact same
   * boolean -- demand and supply can never drift apart the way
   * `hasHydrology` alone would let them (see the module-header comment on
   * `hasHydrology` above).
   *
   * Distance per region comes from `riverFeatureAt` (river-sample.ts),
   * already in metres in the region's own tangent plane -- no chord/radius
   * conversion needed. Use the OUTWARD (wet-edge) distance,
   * `Math.max(0, feature.distanceM - feature.wetRadiusM)`, matching
   * regional-landform.ts's own idiom: the raw `distanceM` is centreline
   * distance and would misjudge wide channels. `riverFeatureAt` returning
   * `null` means "beyond boundsM +/- 3000 m" for that region, so it is
   * simply excluded from the minimum (never lowers `nearestM`) rather than
   * treated as near.
   */
  private get needsFineContact(): boolean {
    if (!this.hasHydrology) { this.fineContactActive = false; this.fineContactCacheValid = false; return false; }
    if (!this.contactFocus) return this.fineContactActive;
    const point = new THREE.Vector3(...this.contactFocus);
    if (this.fineContactCacheValid && point.distanceTo(this.fineContactCachePoint) < PlanetRenderer.FINE_CONTACT_CACHE_MOVE_M) return this.fineContactActive;
    this.fineContactCachePoint.copy(point);
    this.fineContactCacheValid = true;
    const dir = point.clone().normalize();
    const d: V3 = [dir.x, dir.y, dir.z];
    let nearestM = Infinity;
    if (this.body.hydrology) {
      const feature = riverFeatureAt(this.body.hydrology, d);
      if (feature) nearestM = Math.min(nearestM, Math.max(0, feature.distanceM - feature.wetRadiusM));
    }
    for (const region of this.body.canonicalRivers ?? []) {
      const feature = riverFeatureAt(region, d);
      if (feature) nearestM = Math.min(nearestM, Math.max(0, feature.distanceM - feature.wetRadiusM));
    }
    const threshold = this.fineContactActive ? PlanetRenderer.FINE_CONTACT_DISENGAGE_M : PlanetRenderer.FINE_CONTACT_ENGAGE_M;
    this.fineContactActive = nearestM <= threshold;
    return this.fineContactActive;
  }

  private startWorker(index:number){
    const generation=(this.workers[index]?.generation??0)+1,restarts=this.workers[index]?.restarts??0;
    const worker=new Worker(new URL('./planet-worker.ts',import.meta.url),{type:'module'});
    const slot={worker,generation,restarts};
    this.workers[index]=slot;
    worker.onmessage=({data})=>{if(!this.disposed&&this.workers[index]===slot)this.inbox.push(data);};
    worker.onerror=(event)=>{
      event.preventDefault();if(this.disposed||this.workers[index]!==slot)return;
      worker.terminate();
      // A single worker's crash cannot be attributed to specific in-flight
      // keys from here; conservatively fail everything pending across the
      // whole pool (the existing retry/backoff below handles the resend).
      for(const key of this.pending)this.failed(key);this.pending.clear();this.inbox=[];
      if(slot.restarts++<3)this.startWorker(index);
      else if(this.workers.every((w,i)=>i===index||w.restarts>=3))for(const t of ROOTS)this.failures.add(tileKey(t));
    };
  }
  private failed(key:string) {
    this.failuresTotal++;
    const attempt=(this.retries.get(key)||0)+1;this.retries.set(key,attempt);
    this.retryAfter.set(key,this.frame+30*2**attempt);
    if(attempt>=3)this.failures.add(key);
  }

  private intersectsWaterRegion(t:Tile){
    if(!this.waterRegion)return false;
    const span=2/2**t.level,bound=Math.min(1.8,span*1.42),center=new THREE.Vector3(...tileDirection(t,.5,.5));
    return center.distanceTo(this.waterRegion.center)<=bound+this.waterRegion.radius;
  }
  // `waterBucket`: the quantized sea level `d` was actually built at (echoed
  // back by planet-worker.ts from the job payload's `waterBucket`, not
  // recomputed here -- a single source of truth). A stale patch can already
  // be resident at this same `key` (the request gate above now sends a
  // rebuild for a bucket mismatch while the old patch keeps rendering); if
  // so it MUST be released here before being overwritten, or its mesh/ocean
  // stay attached to `this.group` forever (a leaked, doubled-up render) and
  // its `bytes` are never subtracted from `this.residentBytes` (a permanent
  // budget leak) -- `this.patches.set(key, ...)` below only ever replaces the
  // Map entry, it does not on its own dispose anything the old entry owned.
  private install(key: string, d: ReturnType<typeof buildTile>, waterBucket: number) {
    this.reflectionRevision++;
    this.retries.delete(key);this.retryAfter.delete(key);
    const stale=this.patches.get(key);
    if(stale)this.release(stale);
    const geometry = new THREE.BufferGeometry();
    geometry.setAttribute('position', new THREE.BufferAttribute(d.positions, 3));
    geometry.setAttribute('parentPosition', new THREE.BufferAttribute(d.parents, 3));
    geometry.setAttribute('surfaceHeight',new THREE.BufferAttribute(d.surfaceHeight,1));
    geometry.setAttribute('parentHeight',new THREE.BufferAttribute(d.parentHeight,1));
    geometry.setAttribute('normal', new THREE.BufferAttribute(d.normals, 3));
    geometry.setAttribute('groundWeights',new THREE.BufferAttribute(d.materials,4,true));
    geometry.setAttribute('uv', new THREE.BufferAttribute(d.uvs, 2));
    geometry.setIndex(new THREE.BufferAttribute(d.indices, 1));
    boundMorphedTerrain(geometry);
    const map = new THREE.DataTexture(d.color, d.width, d.width);
    map.colorSpace = THREE.SRGBColorSpace;
    map.minFilter = THREE.LinearMipmapLinearFilter;map.magFilter = THREE.LinearFilter;
    map.generateMipmaps = true;
    // This texture is the actual coastline/terrain colour map: with no
    // anisotropic filtering it undersampled at the oblique viewing angles an
    // orbital or low-altitude view sees, aliasing into jagged coastlines and
    // (up close, where the same texels stretch over sharp view angles at the
    // horizon) visibly blurry ground detail. Matches this.groundAtlas.
    map.anisotropy = this.anisotropy;
    map.needsUpdate = true;
    const material = new THREE.MeshStandardMaterial({map, roughness: this.body.water ? .72 : .95});
    const morph = {value: 0};
    const detail={value:0};
    const edge={value:new THREE.Vector4()};
    const localEye={value:new THREE.Vector3()};
    material.onBeforeCompile = shader => {
      shader.uniforms.patchMorph = morph;
      shader.uniforms.patchEdges=edge;
      shader.uniforms.patchTexels={value:d.width-2};
      shader.uniforms.tileAnchor={value:new THREE.Vector3(...d.anchor)};
      shader.uniforms.atlasLocalEyeM=localEye;shader.uniforms.atlasEyeHeightM=this.eyeHeightUniform;shader.uniforms.atlasSun=this.sunUniform;
      shader.uniforms.atlasRadius={value:this.body.radiusM};
      shader.uniforms.atlasAir=this.localAirUniform;
      shader.uniforms.groundHabitat={value:this.body.water>0&&this.body.temperatureK>=250&&this.body.temperatureK<=325&&this.body.type!=='Ice world'&&this.body.type!=='Volcanic world'?1:0};
      shader.uniforms.atlasRelief={value:this.relief};
      shader.uniforms.groundAtlas={value:this.groundAtlas};
      shader.uniforms.groundEnabled=this.groundEnabled;
      shader.uniforms.groundPatch=detail;
      shader.uniforms.groundOrigin={value:new THREE.Vector3(...detailOrigin(d.anchor,this.body.radiusM))};
      shader.vertexShader = patchMorphHeader+'attribute float surfaceHeight,parentHeight; uniform vec3 tileAnchor; varying vec3 atlasSurface,atlasLocalM; varying float atlasHeightM;\n' + shader.vertexShader;
      shader.vertexShader = shader.vertexShader.replace('#include <begin_vertex>', `${patchMorphVertex} atlasSurface=transformed+tileAnchor;
        atlasLocalM=transformed*atlasRadius; atlasHeightM=mix(parentHeight,surfaceHeight,patchBlend); ${groundVertex}`);
      shader.vertexShader=groundVertexHeader+'\n'+shader.vertexShader;
      shader.fragmentShader='uniform vec3 atlasLocalEyeM,atlasSun;uniform float atlasRadius,atlasAir,atlasRelief,atlasEyeHeightM;varying vec3 atlasSurface,atlasLocalM;varying float atlasHeightM;\n'+shader.fragmentShader;
      shader.fragmentShader=groundFragmentHeader+shader.fragmentShader;
      shader.fragmentShader=localAerialGLSL+shader.fragmentShader;
      shader.fragmentShader=shader.fragmentShader.replace('#include <map_fragment>',`#include <map_fragment>
        ${groundColor}`);
      shader.fragmentShader=shader.fragmentShader.replace('#include <roughnessmap_fragment>','#include <roughnessmap_fragment>\nroughnessFactor=mix(roughnessFactor,dot(groundW,vec4(.96,.92,.84,.73)),groundFade);');
      shader.fragmentShader=shader.fragmentShader.replace('#include <normal_fragment_maps>','#include <normal_fragment_maps>\n'+groundNormalCode);
      shader.fragmentShader=shader.fragmentShader.replace('#include <opaque_fragment>', `
        outgoingLight=atlasApplyLocalAir(outgoingLight,length(atlasLocalEyeM-atlasLocalM),
          atlasEyeHeightM,atlasHeightM,dot(normalize(atlasSurface),atlasSun),atlasAir);
        #include <opaque_fragment>`);
    };
    material.customProgramCacheKey = () => 'planet-patch-ground-bed-v8/'+LOCAL_AERIAL_VERSION;
    const mesh = new THREE.Mesh(geometry, material);
    mesh.receiveShadow=true;mesh.castShadow=true;material.shadowSide=THREE.DoubleSide;
    mesh.customDepthMaterial=terrainDepthMaterial(morph,edge,d.width-2);
    mesh.position.set(...d.anchor);
    mesh.visible = false;
    mesh.userData.planetTile = key;
    // Retained off-camera shadow casters are culled separately by each camera.
    mesh.frustumCulled = true;
    this.group.add(mesh);
    let ocean:Patch['ocean']=null;
    if(d.oceanPositions&&d.oceanParents&&!oceanPatchCullProof({positions:d.positions,parents:d.parents,oceanPositions:d.oceanPositions,oceanParents:d.oceanParents,baseVertices:(PATCH_SEGMENTS+1)**2,anchorDir:d.anchor,radiusM:this.body.radiusM}).canCull){
      const waterGeometry=new THREE.BufferGeometry();
      waterGeometry.setAttribute('position',new THREE.BufferAttribute(d.oceanPositions,3));
      waterGeometry.setAttribute('parentPosition',new THREE.BufferAttribute(d.oceanParents,3));
      waterGeometry.setAttribute('uv',geometry.getAttribute('uv'));
      waterGeometry.setIndex(geometry.index);waterGeometry.setDrawRange(0,PATCH_SEGMENTS*PATCH_SEGMENTS*6);
      const normalAnchorDir=new THREE.Vector3(...d.anchor).normalize().toArray() as V3;
      const waterMaterial=createOceanWaterMaterial({radiusM:this.body.radiusM,normalAnchorDir,phaseOriginM:detailOrigin(d.anchor,this.body.radiusM),patchMorph:morph,patchEdges:edge,patchTexels:{value:d.width-2},waveSeed:hashSeedString(this.body.seed+'/'+this.body.id)});
      ocean=new THREE.Mesh(waterGeometry,waterMaterial);ocean.position.copy(mesh.position);ocean.visible=false;ocean.frustumCulled=false;
      this.group.add(ocean);
    }
    const bufferBytes=d.positions.byteLength+d.parents.byteLength+d.normals.byteLength+d.materials.byteLength+d.uvs.byteLength+d.indices.byteLength+d.surfaceHeight.byteLength+d.parentHeight.byteLength+(d.oceanPositions?.byteLength||0)+(d.oceanParents?.byteLength||0);
    const bytes=bufferBytes*2+Math.ceil(d.color.byteLength*(1+4/3));
    this.patches.set(key, {tile: d.tile, mesh, ocean,localEye,map, material, morph, detail,edge,data:d,bytes,touched: this.frame,waterBucket});
    this.residentBytes+=bytes;
  }
  // `worldNs`: elapsed Ns since the Big Bang (world-time.ts's absolute axis).
  // ALREADY WIRED: main.ts:2431 passes its own `epoch` variable as this 8th
  // argument (`planetTiles.update(local, innerHeight, camera.fov, dt,
  // renderer.xr.isPresenting, sun, frusta, epoch, lifeGateContext(...))`), so
  // cloud advection, ring birth/death and (as of this change) the ocean/river
  // wave phase all track the app's actual travel date. Optional and appended
  // last only so any hypothetical caller that predates this wiring keeps
  // compiling. Defaulting to CATALOGUE_EPOCH_NS (the documented
  // "oldEpoch === 0" reference date, i.e. today) is deliberate: it is the
  // same zero point main.ts itself starts from before any date scrubbing, so
  // an unwired caller would show the same "present day" sky a wired one
  // shows at app launch. (Earlier revisions of this comment described this
  // as an unwired "Package D hook" -- that was true when written but is
  // stale; corrected 2026-09-17 alongside the ocean/river wall-clock fix.)
  // `waterLevelM` (new, appended last, default `0` -- today's behaviour):
  // main.ts's `updatePlanetTiles` resolves this via `waterLevelAt(waterKeysFor(
  // bodyEntry.lc, bodyEntry.starLc), epoch)` (0 for a star) and passes it here
  // alongside `worldNs`/`life`, mirroring that argument's own existing
  // precedent -- this file deliberately does NOT import `stellar-evolution.ts`
  // to resolve it itself. Quantized immediately (`waterLevelBucket`, see that
  // constant's own doc) into `waterBucket`/`snappedWaterLevelM`: every tile
  // job dispatched this frame, and `this.sample`/`this.classify` whenever the
  // bucket changes, use the SAME snapped value, so any two tiles that share a
  // bucket are bit-identical at their shared edge by construction.
  update(observer: V3, height: number, fov: number, dt: number, immersive = false, sun: V3 = [1,0,0], frusta: THREE.Frustum[] = [], worldNs: bigint = CATALOGUE_EPOCH_NS, life: LifeGateContext | null = this.lifeContext, waterLevelM: number = 0,shadowFrustum:THREE.Frustum|null=null) {
    if (this.disposed) return;
    this.immersiveBudget=immersive;
    this.lifeContext = life;
    const started=performance.now();
    this.frame++;
    const waterBucket=waterLevelBucket(waterLevelM), snappedWaterLevelM=waterBucket*WATER_LEVEL_BUCKET_M;
    // `this.sample`/`this.classify` are long-lived closures (built once in the
    // constructor), unlike `buildTile`'s per-tile bake below -- refresh them
    // in place only when the bucket actually moves, so `projected()`'s
    // approximate distance estimate and the life layer's biome/ocean gate
    // (`updateLife`'s `this.classify` call) stay consistent with whatever sea
    // level newly-built tiles are now using, without reallocating every frame.
    if(waterBucket!==this.waterBucket){
      this.waterBucket=waterBucket;
      this.sample=terrainSampler(this.body,undefined,this.surfaceAgeMyr,undefined,snappedWaterLevelM);
      this.classify=biomeClassifier(this.body,snappedWaterLevelM);
    }
    // At most two completions become GPU resources per animation frame.
    const completions=this.debug.freezeSelection?[]:this.inbox.splice(0,2);
    for (const message of completions) {
      this.pending.delete(message.key);
      if (message.result) this.install(message.key, message.result, message.waterBucket??0);
      else this.failed(message.key);
    }
    const wanted: Tile[] = [], protectedKeys = new Set<string>();
    const request = (t: Tile) => {
      const key = tileKey(t);
      protectedKeys.add(key);
      // A resident patch built at a different sea-level bucket is treated as
      // "not resident" here -- exactly like a missing tile, it is handed to
      // the same async streaming queue below (never rebuilt synchronously).
      // It keeps rendering (still internally coherent, see the module-level
      // `WATER_LEVEL_BUCKET_M` doc) until the rebuild lands and `install`
      // replaces it in place.
      const resident=this.patches.get(key), fresh=!!resident&&resident.waterBucket===waterBucket;
      if (!fresh && !this.pending.has(key) && !this.failures.has(key)&&(this.retryAfter.get(key)||0)<=this.frame) wanted.push(t);
    };
    for (const t of ROOTS) request(t);
    this.rootsReady = ROOTS.every(t => this.patches.has(tileKey(t)));
    const eye = new THREE.Vector3(...observer), distance = eye.length();
    const contact=this.contactFocus?new THREE.Vector3(...this.contactFocus).divideScalar(this.body.radiusM):null;
    const contactDirection=contact?.clone().normalize();
    const groundDirection=eye.clone().normalize().toArray() as V3;
    const groundHeight=this.sample(groundDirection).visibleHeightM;
    const altitudeM=(distance-1)*this.body.radiusM-groundHeight;
    this.lowFlightDetail=!immersive&&altitudeM<PLANET_DETAIL.flightDetailAltitudeM;
    // 390 active walking leaves plus their protected ancestors fit beneath the
    // terrain reserve while leaving admission headroom for newly requested
    // contact chunks. A 512-leaf full quadtree can consume that headroom.
    const cacheLimit=contact||this.lowFlightDetail?768:TILE_CACHE_LIMIT,drawLimit=contact?450:this.lowFlightDetail?390:(immersive?102:TILE_DRAW_LIMIT);
    this.eyeHeightUniform.value=(distance-1)*this.body.radiusM;this.sunUniform.value.set(...sun);
    this.atmosphere?.update(eye, new THREE.Vector3(...sun));
    this.clouds?.update(this.body.seed,this.body.id,worldNs,this.sunUniform.value);
    // Ring existence toggle only -- geometry/texture are baked once at
    // construction (ringSystemFor/createRingMesh are pure functions of the
    // body, not of time), so this is a cheap per-frame boolean, not a rebuild.
    // See the constructor's ringParams comment and this method's `worldNs`
    // doc for why the current absolute Ns is used here as a stand-in for
    // "elapsed since the body's own formation" (this module's real birthNs/
    // deathNs zero point) rather than the true value.
    if(this.ring)this.ring.visible=ringActiveAt(this.ringSystem!,worldNs);
    // Ocean/river wave phase: a pure function of simulated worldNs (contract
    // §2.6, "the animator is now NAMED"), never of wall-clock dt. Computed
    // once here and passed unchanged to both consumers below so the sea and
    // its rivers agree bit-for-bit on the same instant. The `freezeWater`
    // debug flag is deliberately NOT consulted here -- both downstream
    // consumers already implement their own frozen-snapshot logic
    // (ocean-water-material.ts's setFrame/setDebug, river-water.ts's
    // setDebug/update), so external freeze behaviour is unchanged.
    const oceanPhaseS=oceanPhaseSeconds(worldNs);

    // moving this focus ahead made turning in place replace dense forest.

    if (this.relief === 1 && (contact||altitudeM<PLANET_DETAIL.groundLifeAltitudeM) && this.lifeContext) { const lifeStarted=performance.now(); this.updateLife(eye, lifeFocus, frusta[0] ?? null, worldNs,shadowFrustum); this.lifeMs=performance.now()-lifeStarted; }
    else { this.hideLife(); this.lifeMs=0; }
    const direction = eye.clone().normalize();
    const pixels = height / (2 * Math.tan(fov * Math.PI / 360));
    if(this.waterRegion){const near=Math.max(1e-9,eye.distanceTo(this.waterRegion.center)-this.waterRegion.radius);this.waterRegionActive=this.waterRegion.radius*pixels/near>=8;}else this.waterRegionActive=false;
    const projectionCache=new Map<string,{visible:boolean;score:number;contactNear:number;waterPriority:boolean;finePriority:boolean}>();

    const viewNormals=retainedFrusta.flatMap(f=>f.planes.flatMap(p=>p.normal.toArray()));

    // Rebuilding a full walking quadtree every 15 idle frames caused periodic
    // CPU stalls. Refine for real pose/projection changes or arriving tiles;
    // conservative visibility culling still runs on every frame below.

    };

      const urgent=Math.max(...leaves.map(t=>t.level<(contact?(this.needsFineContact?this.fineContactLevel:this.contactLevel):this.contactLevel)?projected(t).score:0));
      for(const leaf of leaves){let t=leaf;while(t.level>0){t={face:t.face,level:t.level-1,x:Math.floor(t.x/2),y:Math.floor(t.y/2)};
        const key=tileKey(t);deepest.set(key,Math.max(deepest.get(key)??0,leaf.level));
        if(t.level===leaf.level-1)parents.set(key,t);}}
      const mergeCandidates=[...parents.entries()],mergeStarted=performance.now();
      if(this.mergeRemaining<=0)this.mergeRemaining=mergeCandidates.length;
      else this.mergeRemaining=Math.min(this.mergeRemaining,mergeCandidates.length);

      const mergeLimit=Math.min(this.mergeRemaining,mergeCandidates.length,64);

        const [key,parent]=mergeCandidates[(mergeStart+scanned++)%mergeCandidates.length];

        if(!this.patches.has(key))continue;
        for(const child of kids){const index=leaves.findIndex(t=>tileKey(t)===tileKey(child));if(index>=0)leaves.splice(index,1);}
        leaves.push(parent);this.selectionDirty=true;
      }
      this.mergeCursor=(mergeStart+scanned)%Math.max(1,mergeCandidates.length);
      this.mergeRemaining=Math.max(0,this.mergeRemaining-scanned);
      if(this.mergeRemaining>0)this.selectionDirty=true;

      for (let iteration = 0; iteration < iterations; iteration++) {
        if(iteration>0&&performance.now()-selectionStarted>3){this.selectionDirty=true;break;}

        const neighbour=(t:Tile,e:number)=>{let n=tileNeighbour(t,e);while(n.level>0&&!index.has(tileKey(n)))n={face:n.face,level:n.level-1,x:Math.floor(n.x/2),y:Math.floor(n.y/2)};return index.get(tileKey(n));};

          const target=contact?(this.needsFineContact?this.fineContactLevel:this.contactLevel):this.lowFlightDetail?this.contactLevel:16;
          if(p.t.level>=target||p.score<=(immersive?360:260))return false;
          // Above the regular contact level, only the 3 m hydrology contact
          // band may refine. This prevents ordinary visible terrain from
          // consuming the fine-band leaf budget.
          return !contact||p.t.level<this.contactLevel||p.contactNear<3||p.score>1e8;
        });
        candidates.sort((a, b) => b.score - a.score);
        const contactPending=!!contact&&candidates.some(c=>c.score>1e8);
        let split = false;
        for (const candidate of candidates) {
          // Request balanced capsule support first. Protecting every distant
          // candidate's children can otherwise pin the entire byte budget
          // while the last mandatory contact tiles still need admission.
          if(contactPending&&candidate.score<1e8)continue;
          // Foot-contact candidates sort first, but do not freeze all visible
          // non-contact terrain after an arbitrary 90 leaves.  The fixed
          // draw/cache limits below remain the allocation boundary, allowing
          // a visible river or lake shore to refine beside the contact ring.
          let t=candidate.t;
          // Every contact split preserves the established 2:1 closure. Edge
          // locks only support one level of difference; bypassing this creates
          // unsupported multi-level seams and skirt walls.
          if(contact){for(let pass=0;pass<20;pass++){const lower=[0,1,2,3].map(e=>neighbour(t,e)).find(n=>n&&n.level<t.level);if(!lower)break;t=lower;}}
          if (leaves.length + 3 > drawLimit) break;
          const kids = children(t);
          kids.forEach(request);
          if (leaves.length + 3 <= drawLimit && kids.every(k => this.patches.has(tileKey(k)))) {
            leaves.splice(leaves.indexOf(t), 1, ...kids);
            split = true;
            if(iteration===iterations-1)this.selectionDirty=true;
            break;
          }
        }
        if (!split) break;
      }
    }
    this.active.clear();
    this.leafIndex=new Map(leaves.map(t=>[tileKey(t),t]));
    this.underresolvedWaterTiles=this.waterRegionActive&&this.minimumWaterLevel!==null?leaves.filter(t=>t.level<this.minimumWaterLevel!&&this.intersectsWaterRegion(t)).length:0;
    for (const p of this.patches.values()){p.mesh.visible = false;if(p.ocean)p.ocean.visible=false;}
    for (const t of leaves) {
      const key = tileKey(t), p = this.patches.get(key);
      // A retained frontier can stop refining while its baked water bucket is
      // stale. Request freshness independently of camera/LOD selection changes.
      // The previous complete tile stays visible until its replacement lands.
      request(t);
      let ancestor=t;while(ancestor.level>0){ancestor={face:ancestor.face,level:ancestor.level-1,x:Math.floor(ancestor.x/2),y:Math.floor(ancestor.y/2)};protectedKeys.add(tileKey(ancestor));}
      if (!p) continue;
      p.touched = this.frame;
      p.mesh.visible = projected(t).visible && this.rootsReady;
      if (p.mesh.visible) this.active.add(key);
      if (!this.previous.has(key)) p.morph.value = t.level ? 0 : 1;
      if(!this.debug.freezeMorph)p.morph.value = Math.min(1, p.morph.value + dt / .22);
      p.localEye.value.copy(eye).sub(p.mesh.position).multiplyScalar(this.body.radiusM);
      if(p.ocean){p.ocean.visible=p.mesh.visible;setOceanWaterPatchFrame(p.ocean.material,{localEyeM:p.localEye.value,sunDirection:this.sunUniform.value,oceanPhaseS});}

      const parent=(n:Tile)=>({face:n.face,level:n.level-1,x:Math.floor(n.x/2),y:Math.floor(n.y/2)});
      const edges=neighbours.map(n=>this.leafIndex.has(tileKey(parent(n)))?1:0);
      p.edge.value.set(edges[0],edges[1],edges[2],edges[3]);
      // Skirts are a streaming fallback. Once neighbouring edges are settled
      // and at most one level apart, edge locks already close the surface.
      // Keeping skirts there lets nearly coplanar vertical faces leak through
      // the log-depth buffer and creates textured fences at ground level.
      const settled=(n:Tile)=>this.previous.has(tileKey(n))&&this.leafIndex.has(tileKey(n))&&this.patches.get(tileKey(n))?.morph.value===1;
      const stitched=p.morph.value===1&&neighbours.every(n=>settled(n)||(n.level>0&&settled(parent(n)))||children(n).every(settled));
      p.mesh.geometry.setDrawRange(0,stitched?PATCH_SEGMENTS*PATCH_SEGMENTS*6:p.data.indices.length);
      const sphere=p.mesh.geometry.boundingSphere!;
      const near=eye.distanceTo(sphere.center.clone().add(p.mesh.position))-sphere.radius;
      p.detail.value=(distance-1)*this.body.radiusM<20000*this.relief+6000&&near*this.body.radiusM<6000?1:0;
      // Contact hand-off is enabled only after fine coverage has finished morphing.
    }
    this.previous = new Set(leaves.map(tileKey));
    // Keep the orbital preview until the focused replacement tree has
    // reached useful resolution. Six coarse root maps caused a blur on focus.
    if(!this.surfaceReady&&this.rootsReady&&
      [...this.active].some(key=>this.patches.get(key)!.tile.level>=3))this.surfaceReady=true;
    this.group.visible=this.surfaceReady;
    this.materialVisible(!this.surfaceReady);
    // Retain ancestor fallback meshes; evict unused children first. Bound also
    // includes pending work, so late completions cannot grow the cache forever.
    // Reserve one worst-case worker result before admitting it. This maintains
    // the combined cap even when a worker completion arrives after selection.
    const bytePressure=()=>this.residentBytes+(this.pending.size+1)*PENDING_TILE_BYTES>this.terrainBudgetBytes;
    for (const p of [...this.patches.values()].sort((a,b) => a.touched - b.touched)) {
      if (this.patches.size + this.pending.size < cacheLimit - 2&&!bytePressure()) break;

      if (!protectedKeys.has(key)) { this.release(p); this.patches.delete(key); }
    }
    const unique = new Map(wanted.map(t => [tileKey(t), t]));
    for (const [key, tile] of unique) {
      if(this.debug.freezeSelection)break;
      // Was a flat cap of 2 in-flight requests even though a single worker
      // could only ever process one at a time; now scaled modestly to the
      // pool (one extra slot per worker) so every worker can have work
      // queued without letting too many completions land in the same frame
      // and burst the main-thread upload/compile work that follows each one.
      if (this.pending.size >= this.workers.length*2 || this.patches.size + this.pending.size >= cacheLimit||this.residentBytes+(this.pending.size+1)*PENDING_TILE_BYTES>this.terrainBudgetBytes) break;
      this.pending.add(key);
      this.workers[this.nextWorker=(this.nextWorker+1)%this.workers.length].worker.postMessage({key, tile, body: this.body, relief: this.relief, waterLevelM: snappedWaterLevelM, waterBucket});
    }
    this.updateMs=performance.now()-started;
  }

  private rescatterLife(point:THREE.Vector3):void {
    this.lifePackingDirty=true;
    const d=point.clone().normalize().toArray() as V3,r=this.body.radiusM;
    const cells:LifeCell[]=[];
    const add=(range:number,size:number,layer:'flora'|'fauna')=>{
      for(const c of surfaceCellsWithin(d,r,range,size))cells.push({...c,id:`${layer}/${size}/${c.id}`,cellSizeM:size,layer});
    };
    // Fine grass remains a bounded neighbourhood; shrubs have the full 120 m
    // draw range. Herd anchors cover visibility + motion + streaming margins.
    add(34,2,'flora');add(120+LIFE_LOAD_MARGIN_M,24,'flora');add(FAUNA_FIELD_VISIBLE_M+LIFE_LOAD_MARGIN_M+16,32,'fauna');
    cells.sort((a,b)=>Math.hypot(a.direction[0]-d[0],a.direction[1]-d[1],a.direction[2]-d[2])-Math.hypot(b.direction[0]-d[0],b.direction[1]-d[1],b.direction[2]-d[2])||a.id.localeCompare(b.id));
    this.lifeWanted=cells;this.lifeQueue=cells.filter(c=>!this.lifeResidents.has(c.id));this.lifeQueueIndex=0;
    // Habitat for visible herds must not wait behind thousands of grass cells.
    this.lifeQueue.sort((a,b)=>(a.layer==='fauna'?0:1)-(b.layer==='fauna'?0:1));
    const wanted=new Set(cells.map(c=>c.id));
    // Retain an extra band to absorb boundary oscillation, without growing a
    // journey-sized cache. Canonical keys survive removal and re-generation.
    for(const [id,record] of this.lifeResidents){
      const range=record.cell.layer==='fauna'?FAUNA_FIELD_VISIBLE_M+140:record.cell.cellSizeM===2?70:210;
      if(!wanted.has(id)&&Math.hypot(record.cell.direction[0]-d[0],record.cell.direction[1]-d[1],record.cell.direction[2]-d[2])*r>range)this.lifeResidents.delete(id);
    }
  }
  private processLifeQueue():void {
    const life=this.lifeContext!,start=performance.now(),r=this.body.radiusM;
    const gate=this.faunaGateScratch;gate.stage=life.faunaStage;gate.availableArchetypes=life.faunaAvailableArchetypes;gate.species=life.faunaSpecies;
    for(let count=0;this.lifeQueueIndex<this.lifeQueue.length&&count<32&&performance.now()-start<2;count++){
      const cell=this.lifeQueue[this.lifeQueueIndex++],d=cell.direction;
      const sample=this.sample(d),up=this.lifeBasisUp.set(...d);
      const ref=Math.abs(up.y)>.92?this.lifeWorldUpScratch.set(1,0,0):this.lifeWorldUpScratch.set(0,1,0);
      const right=this.lifeBasisRight.crossVectors(ref,up).normalize(),forward=this.lifeBasisForward.crossVectors(up,right).normalize();
      const offset=(basis:THREE.Vector3,metres:number)=>{
        this.floraScratchDirVec.copy(up).addScaledVector(basis,metres/r).normalize();
        return this.sample(this.floraScratchDirVec.toArray() as V3).groundHeightM;
      };

      const classified=this.classify(d,sample.groundHeightM,1/Math.sqrt(1+gx*gx+gz*gz));
      const biome:FloraBiomeSample={...classified,weights:classified.weights as [number,number,number,number]};
      // Preserve the original canonical fauna key, independent of queue/grid.
      const canonicalId=cell.id.split('/').slice(2).join('/');
      const herd=cell.layer==='fauna'?faunaHerdAt(this.body.seed,this.body.id,d,biome,gate,toSeconds(0),canonicalId):null;
      const resident:LifeResident={cell,height:sample.groundHeightM,biome,herd,ground:herd?.present?new Float64Array(FAUNA_GROUND_N**2):null,groundCursor:0};
      this.lifeResidents.set(cell.id,resident);this.lifePackingDirty=true;if(resident.ground)this.faunaGroundQueue.push(resident);
    }
    // Finish immutable herd terrain stencils incrementally; a herd is only
    // published once its entire stencil exists, avoiding elevation changes.
    for(let count=0;this.faunaGroundQueue.length&&count<32&&performance.now()-start<3;count++){
      const record=this.faunaGroundQueue[0];
      if(!this.lifeResidents.has(record.cell.id)){this.faunaGroundQueue.shift();continue;}
      const up=this.lifeBasisUp.set(...record.cell.direction),ref=Math.abs(up.y)>.92?this.lifeWorldUpScratch.set(1,0,0):this.lifeWorldUpScratch.set(0,1,0);
      const right=this.lifeBasisRight.crossVectors(ref,up).normalize(),forward=this.lifeBasisForward.crossVectors(up,right).normalize();
      const index=record.groundCursor++,x=(index%FAUNA_GROUND_N)*FAUNA_GROUND_STEP_M-FAUNA_GROUND_HALF_M,z=Math.floor(index/FAUNA_GROUND_N)*FAUNA_GROUND_STEP_M-FAUNA_GROUND_HALF_M;
      this.faunaGroundDirScratch.copy(up).addScaledVector(right,x/r).addScaledVector(forward,z/r).normalize();
      record.ground![index]=this.sample(this.faunaGroundDirScratch.toArray() as V3).groundHeightM;
      if(record.groundCursor===FAUNA_GROUND_N**2){this.faunaGroundQueue.shift();this.lifePackingDirty=true;}
    }
    // The packed habitat and herd anchors are immutable between arrivals,
    // completed terrain stencils and changed demand. Poses still update below.
    if(!this.lifePackingDirty)return;
    this.lifePackingDirty=false;this.lifePackBuilds++;
    let flora=0,fauna=0,herds=0;
    for(const cell of this.lifeWanted){
      const record=this.lifeResidents.get(cell.id);if(!record)continue;
      if(cell.layer==='fauna'){
        if(!record.herd?.present||record.groundCursor<FAUNA_GROUND_N**2)continue;
        this.faunaAnchorDirections.set(cell.direction,fauna*3);this.faunaSurfaces[fauna]=record;this.faunaHerds[fauna++]=record.herd;herds++;continue;
      }
      if(flora>=LIFE_SLOT_CAPACITY)continue;

      const b=record.biome;this.floraSlotDir.set(cell.direction,flora*3);this.floraSlotHeightM[flora]=record.height;
      this.floraSlotWeights.set(b.weights,flora*4);this.floraSlotForest[flora]=b.forestPotential?1:0;
      this.floraSlotMoisture[flora]=b.moisture;this.floraSlotSlopeDeg[flora]=b.slopeDeg;this.floraSlotOcean[flora]=b.ocean?1:0;flora++;

/** This snapshot receives the already dated catalogue from main. It neither
 * invents species nor evaluates a second date or lifecycle model. */
export function forestTreeCatalogue(species:readonly Species[]){
  const trees=species.filter(s=>s.kind==='tree'&&(s.family==='branching'||s.family==='spire')).slice().sort((a,b)=>a.id.localeCompare(b.id));
  const recipes=new Map(trees.map(s=>[s.id,treeSpeciesRecipe(s)]));
  if(recipes.size!==trees.length)throw new Error('Duplicate dated tree species');
  const signature=JSON.stringify([...recipes.values()]);
  return {signature,count:trees.length,
    resolve(cellId:string){
      const species=bindTreeSpecies(cellId,trees);if(!species)return null;
      const recipe=recipes.get(species.id)!;
      return {recipe,appearance:treeInstanceAppearance(recipe,cellId)};
    },
  };
}

/** Presentation contract only: never part of canonical surface-cell addresses. */
export const TREE_RECIPE_VERSION='tree-recipe-1';

export type TreeSpeciesRecipe=Readonly<{
  version:typeof TREE_RECIPE_VERSION; speciesId:string; lineageId:string;
  family:'branching'|'spire'; sourceFingerprint:string;
  heightM:number; crownWidthM:number; trunkDiameterM:number;

function hash(text:string){
  let h=2166136261;
  for(let i=0;i<text.length;i++){h^=text.charCodeAt(i);h=Math.imul(h,16777619);}
  h^=h>>>16;h=Math.imul(h,0x7feb352d);h^=h>>>15;h=Math.imul(h,0x846ca68b);
  return (h^(h>>>16))>>>0;
}
const unit=(...parts:unknown[])=>hash(JSON.stringify(parts))/0x100000000;

/** The caller supplies the already dated/eligible catalogue species. Rendezvous
 * assignment is independent of enumeration order and unrelated non-tree species.
 * Adding a tree species can transfer some assignments; it does not move cells. */
export function bindTreeSpecies(cellId:string,eligibleSpecies:readonly Species[]):Species|null {
  if(!cellId)throw new Error('Canonical cell id is required');
  let chosen:Species|null=null,best=-1;
  for(const species of eligibleSpecies){
    if(species.kind!=='tree'||(species.family!=='branching'&&species.family!=='spire'))continue;
    const score=hash(JSON.stringify([cellId,species.id,'tree-species-binding-1']));
    if(score>best||(score===best&&species.id<(chosen?.id??''))){chosen=species;best=score;}
  }
  return chosen;
}

/** Convert existing catalogue traits into a physical rendering envelope. The
 * trunk/crown relationship is an art heuristic, not a botanical simulation. */
export function treeSpeciesRecipe(species:Species):TreeSpeciesRecipe {
  if(!species.id||!species.lineageId)throw new Error('Catalogue species and lineage ids are required');
  if(species.kind!=='tree'||(species.family!=='branching'&&species.family!=='spire'))throw new Error('A catalogue tree species is required');
  const t=species.traits;
  for(const key of ['heightM','widthRatio','branchCount','branchAngle','curvature','leafLength','leafWidth','leafDensity'] as const)
    if(!Number.isFinite(t[key]))throw new Error(`Non-finite tree trait ${key}`);
  if(t.heightM<=0||t.widthRatio<=0||t.leafLength<=0||t.leafWidth<=0||t.branchCount<1||t.leafDensity<0||t.leafDensity>1)throw new Error('Invalid tree physical envelope');
  if(!/^#[0-9a-f]{6}$/i.test(t.color)||!/^#[0-9a-f]{6}$/i.test(t.woodColor))throw new Error('Tree colours must be sRGB hex');
  const source=[species.id,species.lineageId,species.family,t.heightM,t.widthRatio,t.branchCount,t.branchAngle,t.curvature,t.leafLength,t.leafWidth,t.leafDensity,t.color,t.woodColor];
  return Object.freeze({version:TREE_RECIPE_VERSION,speciesId:species.id,lineageId:species.lineageId,family:species.family,
    sourceFingerprint:hash(JSON.stringify(source)).toString(16).padStart(8,'0'),
    heightM:t.heightM,crownWidthM:t.heightM*t.widthRatio,
    trunkDiameterM:t.heightM*(species.family==='spire'?.026:.034),
    branchCount:Math.round(t.branchCount),branchAngleRad:t.branchAngle,curvature:t.curvature,
    leafLengthM:t.leafLength,leafWidthM:t.leafWidth,leafDensity:t.leafDensity,
    barkSRGB:t.woodColor,foliageSRGB:t.color});
}

export function treeStructuralVariant(recipe:TreeSpeciesRecipe,variant:number){
  if(!Number.isInteger(variant)||variant<0||variant>=TREE_VARIANT_COUNT)throw new Error('Tree variant is outside the bounded pool');
  const u=(channel:string)=>unit(recipe.version,recipe.speciesId,recipe.sourceFingerprint,variant,channel);
  const heightScale=.94+.12*u('height'),crownScale=.93+.14*u('crown');
  return Object.freeze({variant,branchSeed:hash(JSON.stringify([recipe.version,recipe.speciesId,variant,'branches'])),
    heightM:recipe.heightM*heightScale,crownWidthM:recipe.crownWidthM*heightScale*crownScale,
    trunkDiameterM:recipe.trunkDiameterM*heightScale,
    branchCount:Math.max(3,Math.round(recipe.branchCount*(.9+.2*u('branches')))),
    branchAngleRad:recipe.branchAngleRad+(.08*u('angle')-.04),
    curvature:recipe.curvature+(.08*u('curve')-.04),
    // Leaves keep their species dimensions when the whole tree grows taller.
    leafLengthM:recipe.leafLengthM,leafWidthM:recipe.leafWidthM,
    leafDensity:Math.min(1,recipe.leafDensity*(.94+.12*u('density')))});
}

/** Cheap per-instance shader parameters. Tints multiply separate bark/leaf
 * masks; they never choose a new topology or a new species. */

# Surface lighting desktop verification

Verified on the local Atlas app at `http://127.0.0.1:5197/`, using Playwright with `ATLAS_HARDWARE=1`. The first run identified `ANGLE (NVIDIA GeForce RTX 5090, Direct3D11)`; the close-up used the same hardware browser configuration. The run tested the legacy forest through the normal LETHRA-001 → Maithea → Find Life path; it did not load experimental family assets.

Runtime source hashes in both reports were unchanged across each run and match the surface-lighting implementation at commit `2f1a6c5`. Head later advanced to `6663ae8` with a separate, unimported foliage-mip helper; that change was not part of these browser captures.

## Captures and behavior

- At 195.3 m, detailed lighting was active with a 320 m × 1000 m shadow region, 2048² map, shadow intensity 1, sky fill 0.7, and ambient intensity 0.088. The broad hillside comparison is [detailed](desktop-run/lighting-detailed.png) and [basic](desktop-run/lighting-basic.png).
- At 11.70 m, the paired [detailed](closeup-run/lighting-detailed.png) and [basic](closeup-run/lighting-basic.png) canvas captures use the same paused camera pose (position delta 0 m; heading delta 1.4e-17). The detailed image shows contact shadows under legacy tree crowns and fauna; basic mode disables the shadow and sky fill and restores ambient intensity to 0.22. The attached full-frame pixel delta is not a lighting-only comparison: the legacy forest count changed from 725 to 493 as caster selection changed with the mode.
- Both browser runs had zero page/console errors and zero GL errors. The surface-lighting control toggled normally. The dated seek kept the feature enabled, but at the tested one-year-shifted date its daylight gate reported `active=false`; that capture is retained as [lighting-dated-detailed.png](closeup-run/lighting-dated-detailed.png). This is not evidence of a dated shadow render.

## Timing and CPU profile

Each lighting mode had a 1.2 s warmup and an 8 s render-profile window. In the close-up run, detailed/basic respectively recorded median/p95 CPU `planetUpdateMs` of 34.4/44.6 and 35.0/42.4 ms; median/p95 instrumented GPU pass sums of 10.81/14.43 and 9.47/11.84 ms. The scene workloads differed: 282 versus 217 draw calls and 1.263M versus 0.855M triangles. Those figures are not a controlled cost comparison, and the profiler does not isolate the shadow pass.

A separate 6.5 s CDP CPU profile was taken after the render-profile windows at the near-ground pose. It collected 4,293 samples. Highest self-sample counts were `PlanetForest.update` 847, `PlanetCanopy.currentPatch` 379, `PlanetRenderer.processLifeQueue` 284, `PlanetCanopy.noteNear` 194, and `PlanetRenderer.update` 179. The raw profile is [cpu-profile.cpuprofile](closeup-run/cpu-profile.cpuprofile); timing attribution is browser sampling, not a deterministic benchmark.

The screenshots show the shadow path operating, but also show faceted crowns, very dark foliage undersides, and hard, high-contrast shadow areas. This is an implementation check, not visual acceptance. Lateral shadow-map edge fade, XR/headset behavior, detailed-family wind/depth interaction, and isolated shadow-pass GPU timing were not verified here.
