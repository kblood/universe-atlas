Separate deterministic simulation workbench

Civilization Lab

The current civilization work is a standalone, seeded Node simulation for developing histories from origins through expansion, collapse, extinction and interstellar travel.

Integration status: The model lives in C:\LLM\IWSDK\civilization-lab. This Atlas page documents the current workbench; it does not run the simulation in the browser or connect it to Atlas planets. The read-only Atlas adapter remains a separate future step.

Current model scenarios

ORIGIN & GROWTH

Lonely Earthlike

Follow one seeded lineage across a long-lived, temperate world.

MULTI-WORLD

Crowded Domain

Inspect several systems, routes, voyages and competing settlement opportunities.

ENVIRONMENTAL LIMITS

Harsh Anoxic

Explore constrained habitability and failure paths under a hostile atmosphere.

STELLAR LIFETIME

Doomed Star

Review the deterministic evacuation and stellar-survival scenario. Its 30-seed audit records 24 lineages lost with their star, five earlier deaths and one tier-7 colony survivor.

RISK & RECOVERY

High Perils

Inspect how seeded hazards, reports and targeting affect civilization histories.

EARLY DEVELOPMENT

Forager Future

Replay a long-horizon path from an early lineage into later technological eras.

Run the workbench locally

From the separate civilization-lab project directory:


 npm test
 npm run scenario
 node src/cli.mjs --scenario lonely-earthlike --seed s1
 node src/cli.mjs --ensemble 8 --scenario doomed-star --jobs 2 --out out/doom

The model is deterministic: it uses seeded RNG streams, stable ordering and a digest for each scenario. Its inputs are authored fixtures today; Atlas climate, biome, resource and travel queries are not yet supplied.
