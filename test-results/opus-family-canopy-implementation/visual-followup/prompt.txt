# Authored trees at a distance

Status: a v2 capture/preview experiment exists, but its silhouettes and one
height-class leaf classification are not accepted. The planetary renderer
still uses its legacy tree shapes. See the [capture-stage record](authored-tree-capture-2026-09-28.md)
for its limited evidence and open gates; this design is not a shipped feature.

## Why a separate representation

The authored pair has 10,712 and 4,820 triangles per tree. Rendering either
through the existing four-kilometre forest would exceed a useful geometry
budget. The current analytic proxy exactly represents the old faceted trees;
it cannot represent the new branches and leaf gaps. Reusing it would introduce
a conspicuous silhouette change during approach.

Epic's [Impostor Baker documentation](https://dev.epicgames.com/documentation/en-us/unreal-engine/impostor-baker-plugin-in-unreal-engine)
describes captures from multiple directions, blending three neighbouring views,
separate material/depth channels and optional parallax correction. It distinguishes
full-sphere and upper-hemisphere captures. Those techniques inform this proposal;
the following budgets and implementation choices are Atlas experiments.

## First experiment

1. Capture the exact authored GLB at rest through a constrained assetctl
   operation. Input must be an approved asset path; outputs go to a fresh
   review directory with source hash, capture version, settings and image hashes.
   Do not accept arbitrary capture scripts or overwrite inputs.
2. Use a full-sphere octahedral direction grid. Free flight, steep terrain and
   cameras below crown centres can require lower views. Start with a 9 by 9
   grid, including duplicate seam directions, and 128-pixel view interiors.
   Measure whether that density suffices before increasing it.
3. Capture unlit base colour plus alpha coverage, object-space normal, depth
   and bark/leaf classification. Data textures stay linear; base colour is
   explicitly sRGB. A sun-lit screenshot is not a reusable material. The
   capture must honour the source alpha cutoff and tangent-space normal map.
4. Keep camera axes, object bounds and root offset in the manifest. Use a
   common enclosing sphere for every view, including wind displacement bounds.
   Store depth in a declared physical interval. Background depth is invalid,
   never a surface at the interval endpoint.
5. Render one instanced camera-facing plane per tree. Choose the enclosing
   triangle of capture directions and blend its three views. Reproject from
   stored depth; reject off-tile/background samples. Reconstruct normals in
   the instance orientation and shade under the same sun/sky as close meshes.
   Derive fragment depth from the reconstructed surface, including the current
   logarithmic-depth contract. Shadow views require their own light direction.
6. Prevent atlas bleeding with per-view padding and explicit mip generation,
   or use WebGL2 texture arrays. Ordinary whole-atlas mipmaps mix unrelated
   views. Test alpha coverage at each supported mip; do not choose a cutoff
   simply to hide a failed silhouette comparison.

## Scale, wind and handoff

Near-tree leaves retain physical size while skeleton height changes from 10 to
22 metres. Uniformly scaling a captured 16-metre tree does not reproduce that
rule. First measure the discrepancy at each height and projected size. If it
exceeds the transition error budget, bake a bounded set of height classes or
delay the switch; do not silently rescale the canonical tree or its leaves.

Wind can settle towards the captured rest pose only while its projected
displacement falls below an explicit screen-space error. Close meshes and
impostors must use the same transition policy. The initial static lab is not
evidence of an acceptable animated game transition.

Use projected size, hysteresis and residency readiness for selection. Keep the
canonical individual, height, yaw, species, variant and tint unchanged.
Complementary coverage must give each pixel one representation during handoff;
avoid drawing both at full opacity. Existing census ownership and worker
residency remain responsible for which trees exist.

## Resource and acceptance gates

Start with one family and one structural variant. Account for mipmapped colour,
normal/depth/classification storage explicitly, including temporary capture
buffers. Do not multiply the present 53.3 MiB source textures by every instance
or variant. Colour tints must affect both distance representations consistently.

Before game integration, compare mesh and impostor at captured and intermediate
directions, octahedron folds, pole/seam crossings, ground/orbit views, tree
heights 10/16/22 m and several yaws. Report silhouette coverage, bounds, root
offset, depth error and light response at the proposed transition sizes. Measure
GPU cost and overdraw at 3/192 trees and at full census density. Include date
replay, load failure, cache eviction and shadow/depth passes. A two-triangle
primitive alone establishes neither speed nor acceptable visual continuity.

The existing asset brief's root/dimension constraint remains in force. Pixel
silhouette error needs a separately reported projected-size tolerance; it must
not be confused with a change to world-space root contact or identity.

## Opus review and implementation decisions

[Opus 5.5 reviewed this design](opus-5.5-tree-distance-review-2026-09-28.md);
[input hashes and returned model](opus-5.5-tree-distance-review-2026-09-28.metadata.json)
identify its source-only scope. Adopt the following for the first baker:

- Use the installed Three renderer through a named assetctl browser operation,
  preserving its alpha, normal-map and physical leaf-size behaviour. Require
  float render-target support, record adapter information, and compare rendered
  results with tolerances rather than promise identical bytes across GPUs.
- Capture at four times the destination width/height, then reduce coverage and
  material channels. Test a 9×9/128-pixel grid against 17×17/64-pixel views.
  Preserve zero coverage for absent views during blending; do not renormalize
  silhouette coverage over only valid views.
- Prototype a linear RGBA16F normal/depth/classification target, alongside
  sRGB colour/coverage. A 9×9×128² pair with full mips costs approximately
  21.3 MiB per height class before source maps and intermediate buffers.
  Three height classes and eight variants would exceed 500 MiB for these
  captures alone. Begin with one class/variant and enforce a cache budget
  before expanding either axis.
- Keep mesh shadow casters within a bounded local region for the first
  experiment. The distant shadow policy is still an acceptance decision.
  Use the same discard pattern on both sides of an ownership transition;
  mixed alpha-to-coverage and discard cannot guarantee complementary coverage.

Several review estimates are hypotheses, not accepted facts. Leaf coverage
does not exactly follow inverse squared height because projected overlap,
orientation and occlusion matter; the suggested alpha exponent cannot replace
height-class comparisons. Octahedral grid spacing is not uniformly 22.5 degrees.
Blending foreground/background depth can create a surface in empty space, so
depth-aware rejection and comparison against mesh depth remain necessary.
Neither the suggested switch distance nor a triangle count proves performance.

# Matching detailed trees and the distant canopy

Status: local implementation; visual acceptance and deployment pending.

The normal Oak/Pine package now supplies the same family information to nearby
mesh instances and the complete distant census. This follows the genuine Opus
[near/far review](opus-near-far-family-assessment-2026-09-28.md); it does not introduce another tree generator or species model.

## Loaded family data

Each loaded LOD produces its own four-band crown profile from its actual leaf
attachment pivots. The distant draw uses LOD1. Bands retain vertical extent,
horizontal visual radius and a separate metric leaf-card margin. Empty bands
do not draw. A separate conservative sphere includes both LOD vertex sets,
supported 10–22 m skeleton heights, leaf wind and the proposed band envelopes.
The visual percentile radius is never used alone as a culling bound.

Base-color images are sampled once at family load. Alpha-weighted sRGB samples
are converted to linear RGB and multiplied by the imported material factor.
This provides separate bark and foliage colors. Atlas alpha occupancy remains
texture metadata; it is not multiplied into the entire crown's opacity.

Family presentation is enabled for a validated offline foliage sidecar. Basic
trees and experimental families without the sidecar keep the legacy distant
representation. The existing normal Trees control remains opt-in.

## Shared dated selection

`PlanetForest` supplies its existing dated catalogue to `PlanetCanopy`.
Canonical cell ID, tree height, position, yaw and habitat membership do not
change. The shared eligibility helper selects only a loaded family supporting
the canonical height. Per-instance bark and foliage brightness use the same
recipe binding as the detailed instances.

Family and both brightness values occupy the previously unused third float
in the far parameter buffer. The packed integer is exact in Float32; brightness
quantization error is at most 0.2/255. Code zero selects the legacy shape and
color. There is no added per-tree GPU attribute.

## Shader and handoff

The existing one-quad-per-tree analytic renderer draws broadleaf ellipsoids or
stacked conifer cones from the loaded middle LOD profile. Skeleton coordinates
scale with canonical height; leaf-card margins remain metres. Derived colors
replace the unrelated legacy green and roll tint for supported families.
The existing actual-hit depth, normals, ownership and local atmosphere remain
in use. Family quads and close-fallback detection use conservative bounds.

A catalogue change or adopted asset-library revision starts a bounded parameter
retag: at most 2,048 retained slots and 2 ms per prepare call. Nearby handoffs
refresh their own tags immediately before pairing. Pairing requires the current
presentation version, matching packed appearance, canonical tree height and
existing ground/root agreement. Retagging preserves transforms and ownership.
The CPU version array uses four bytes per allocated far slot (917,504 bytes at
229,376 slots). Diagnostics report pending retags, processed slots and slice time.

The focused integration run currently passes 67 checks across the far renderer,
canopy lifecycle, detailed family attachment and retained forest work list.
It covers bounded parameter writes, untouched roots/rotations, dated retagging,
height and appearance mismatch rejection, and shared catalogue/library choice.
Shader-source composition checks are not proof of browser GPU compilation.
The metadata and runtime changes also pass the TypeScript check. Detailed-tree
diagnostics include separate handoff samples so browser checks can compare the
near canonical ID against its far slot's height, appearance code and ownership.

This is an analytic approximation. The trunk still uses the legacy trunk shape

profile shape and linear albedo alone cannot reproduce leaf-card holes, normal

   experiment and record the resulting shadow edge instead of implying matched
   multisample shadows.
2. **Coverage-preserving mip chain:** make a test-only mip chain from the exact
   embedded foliage PNG. Downsample alpha, then for every level find the alpha
   remap that preserves the base level's fraction of texels above the GLB's
   0.5 cutoff. Filter RGB in linear light with alpha weighting to avoid dark
   RGB leaking from transparent texels, then encode it back to sRGB. The
   current Three.js `Texture.mipmaps` upload path accepts an explicit level
   array, including the base image, when `generateMipmaps` is false; use a
   lab-only texture copy so the source GLB and shipped default stay unchanged.
   Compare coverage-preserving mips alone first; test it combined with
   alpha-to-coverage only if the individual results justify the extra mode.

For Atlas's leaf atlas, also measure coverage within each leaf cell. Preserving
only the whole texture's average could conceal losses in a sparse cell while
increasing coverage in a denser one. This is a test requirement for the adapter,
not a claim that the current textures have such a mip chain.

`alphaHash` trades hard cutout edges for a stochastic threshold. The corrected
isolated comparison measures increased coverage variation under 0.5° yaw
steps and at the moving wind date relative to its downsampled sample; it does
not establish whether that pattern is perceptually acceptable. Atlas does not
use a general TAA resolve in this tree path.

The offline method is established: Ignacio Castaño's original alpha-mipmap
method solves for a per-level remap that preserves coverage at a chosen alpha
reference. Current DirectXTex `texconv` still exposes `--keep-coverage <ref>`.
However, Atlas's tree authoring operation validates embedded 8-bit PNGs, and
the local `assetctl texture` KTX2 command generates ordinary mips with
`toktx --genmipmap`; it has no coverage-preservation option. A DirectXTex DDS
chain is therefore a useful offline reference, not a drop-in tree artifact.
The smallest initial test is to feed precomputed levels to the lab's Three.js
texture copy. Changing the tree exporter/GLB texture contract is a separate
decision after the visual comparison.

## Keep impostor atlas bleed as a separate issue

The Three.ez baseline packs 16 × 16 capture views into one texture atlas and
lets the renderer generate mips for the whole atlas. Ordinary whole-image
downsampling mixes adjacent view cells at coarse levels; bilinear samples can
also cross a cell edge without guard texels. This can cause repeating colour
and alpha coverage from neighbouring views. It is separate from foliage alpha
coverage loss on the native mesh.

If the native-resolution Three.ez comparison still justifies that renderer,
test per-cell mip generation with edge dilation/gutters and cell-clamped UVs
as an atlas-specific follow-up. Do not use its larger 32 px weighted area as
evidence that the native mesh's alpha mip chain is fixed.

# Review: Atlas tree capture reconstruction

Load validation and the mip upload path look sound. The 0.9993 IoU on exact views shows the capture/basis contract is right. The 0.72 IoU on arbitrary views and the MASK coverage loss have identifiable causes, covered below in priority order.

## Correctness fixes

**1. Filtering is unpremultiplied (highest impact).**
- Colour, normal/depth, and leaf fraction are sampled bilinearly and trilinearly across silhouette edges next to empty texels.
- At leaf edges this causes:
  - dark or background halos in colour;
  - `data.w` pulled toward whatever empty texels hold, which corrupts the parallax solve;
  - leaf fraction falling toward 0, so edges get bark roughness.
- Fix: store `rgb·a`, `n·a`, `w·a` and `leaf·a`, and do the same in the SSAA area mips. After sampling, divide by `a`.
- Check the baker first: if mips were area-averaged over empty texels without coverage weighting, the stored mips are biased as well.

**2. The parallax solve is unconverged.**
- `captureSample` does two fixed-point steps on a single-layer heightfield.
- At foliage depth discontinuities, fixed-point iteration oscillates or lands on empty-texel depth.
- Replace it with a bounded march, as in parallax occlusion mapping:
  - step `w` from +1 to −1 in 8–16 steps at `captureMip`;
  - the first step where coverage ≥ 0.5 and ray height ≤ surface depth is the hit;
  - refine with 2–3 bisection steps.
- Add a unit capture of a known tilted quad and a sphere to pin down the sign of `data.w`. The formula `t=(plane+w·R)/denominator` assumes +w points toward the camera.

**3. `hitDistance` pops.**
- It takes the minimum `t` over any view with weight > 0.001, so a view contributing 0.2% can decide depth.
- Use the maximum-weight view's `t`, or a coverage-weighted `t`.

**4. Dither is screen-space.** `captureNoise(gl_FragCoord.xy)` swims under camera motion. Two options:
- Hash the reconstructed object-space hit (Wyman hashed alpha, quantized by the derivative of the hit position). This is the same family as Three's `alphaHash`, which hashes `vPosition`.
- Set `alphaToCoverage` on the MSAA target and output coverage in alpha, overriding `opaque_fragment`'s forced 1.

**5. `vViewPosition` is still the billboard plane.**
- Specular view vectors, and later point lights, fog and shadow coordinates, use the plane position rather than the hit.
- Negligible for a distant sun, but wrong in principle.
- Define a local hit-position view vector and `#define` it over the uses after `normal_fragment_begin`.

**6. Billboard scale.**
- `d/(d−R)` is over-conservative and explodes as the camera nears the bounding sphere.
- Use `d/sqrt(d²−R²)`. Below roughly 1.1R, reject or hand off to the mesh rather than clamping to 0.01.

**7. Load and lifecycle.**
- The array-layer limit check throws inside `onBeforeRender` every frame. Move it to load.
- Validate `manifest.artifacts` as an array.
- `onBeforeRender` allocates Matrix4 and Vector3 objects per frame.

**8. Normals.**
- Confirm the baker flips double-sided leaf normals toward the capture camera. Otherwise back-facing cards shade dark.
- Mip-averaged normals shorten before `normalize`. Feed `1−|n|` into roughness (Toksvig-style) instead of discarding it; this matters most at 32–64 px.

## Measuring normals, shading and depth

**Debug outputs.** Add a `captureDebug` uniform to the impostor and a matching injection into the mesh mask hook. Modes:
- coverage, albedo, view normal, linear view depth, leaf fraction;
- selected layers and weights (impostor only).

Read these into a HalfFloat target; RGBA8 can't measure depth or normal error. Report:
- coverage IoU;
- coverage-weighted angular normal error;
- depth error in metres;
- linear albedo RMSE;
- leaf-fraction error.

**Held-out views.**
- Capture once at 17×17. Its even-index vertices are exactly the 9×9 grid, with identical `decodeTreeView` bases.
- Reconstruct the odd views from the 9×9 subset and compare against the true captures from the same pipeline.
- This isolates interpolation error from mesh-versus-capture rasterization differences. Plot error against angular distance to the nearest captured view.

**Lit comparison.**
- Use `NoToneMapping`, a sweep of about 6 sun directions, and compare linear luminance RMSE after SSAA.
- Because the albedo capture carries no occlusion, expect the impostor to read brighter inside the canopy. Measure that gap before deciding on an AO channel.

**Depth.**
- Intersect the impostor and the mesh with a vertical plane through the centre and compare the intersection masks.
- Sweep the camera across one blend cell in small steps. Log frame-to-frame coverage change for flicker and depth jumps for popping.

**Scale-separated IoU.**
- Report IoU after a Gaussian blur at the target pixel size as well as raw.
- The raw 0.72 mixes silhouette misregistration, which is fixable, with leaf-level parallax a single depth layer cannot represent. Only the blurred number should gate decisions.

## 9×9 versus 17×17

- **Current spacing:** full-sphere 9×9 has 16 equator samples, about 22.5° apart.
- **17×17 cost:**
  - it has 289 layers, which exceeds WebGL2's guaranteed minimum `MAX_ARRAY_TEXTURE_LAYERS` of 256;
  - at 128 px it costs about 101 MB per height/variant, against 28.3 MB now.
- **Recommended alternative:** unless below-horizon views are a real requirement (cliffs, flight underneath), test a **hemi-octahedral 9×9**.
  - It gives 32 equator samples, about 11.25°, the same as full 17×17, with 81 layers.
  - Version it as a new view contract.
- **Decide with data:** use the held-out measurements after fixes 1–3. Parallax error in pixels scales with projected size, so 9×9 may already pass at the ≤64 px distances where impostors actually render.
- **Smaller saving:** move leaf fraction off an RGBA8 texture that uses only R (about 25% of current bytes).

## Threshold-limited foliage

The 22 m / 32 px bake with no leaves is a baker bug, not a data curiosity. The alpha test runs on averaged alpha mips at the capture resolution.

**Establish ground truth first.**
- Render the mesh with mip 0 forced (no min-filter mips) at 2048 or more.
- Area-reduce to 32, 64 and 128. The probe currently caps supersampling at 4 and total size at 2048, so extend it to 8 or 16.
- The current 32/64 references are undersampled, so the +3%/+1% hash bias isn't established yet. Don't tune against it.

**Bake fix, pick one:**
- **(a)** Force leaf-texture LOD 0 during capture with at least 8×8 SSAA, then area-reduce. This is exact and brute-force.
- **(b)** Coverage-preserving alpha mips: rescale each mip so its coverage at the cutoff matches mip 0. This also fixes the runtime MASK mesh.

**Contract.**
- Keep native MASK as the historical contract.
- Record the foliage coverage mode (`mask` / `mask-lod0` / `hash-object`) in the manifest and include it in the version check, so existing byte audits stay valid.
- Make `alphaHash` opt-in at runtime.

**Handoff.** The mesh-to-impostor handoff must compare against whichever mode the near mesh actually uses. Otherwise canopy density visibly steps at the switch.

## Suggested order

1. Premultiply (in the baker and loader).
2. Marched parallax and depth-sign unit test.
3. `hitDistance` and hash fixes.
4. Debug channels, held-out 17×17 harness and ground-truth reference.
5. Only then decide 9×9, hemi-octahedral or 17×17, and the foliage bake mode.

  private detailedSamples(){
    const samples=[];
    for(const entry of this.assets.entries.values())for(let batch=0;batch<2;batch++){
      if(!this.group.visible||!entry.batches[batch].group.visible)continue;
      let count=0;
      // Diagnostics are read by the live HUD. Bound both scans and output,
      // rather than allocating/filtering every resident on every read.
      const slots=entry.pools[batch].states;
      for(let index=0;index<Math.min(slots.length,64)&&count<8;index++){
        const slot=slots[index],heightM=slot.resident.cell.heightM;
        if(heightM<10||heightM>22)continue;
        const binding=this.binding(slot.resident);if(!binding)continue;
        samples.push({batch,family:entry.kind,id:slot.resident.cell.id,speciesId:binding.recipe.speciesId,
          recipe:binding.recipe.sourceFingerprint,heightM,...binding.appearance});count++;
      }
    }
    return samples;
  }
  private setCatalogue(species:readonly Species[]|undefined){
    if(species===this.catalogueInput)return;
    this.catalogueInput=species;

    try{next=forestTreeCatalogue(species??[]);this.catalogueError='';}
    catch(error){
      // Reject malformed presentation data without interrupting the canonical
      // forest or retrying the same immutable dated snapshot every frame.
      this.catalogueError=String(error);next=forestTreeCatalogue([]);
    }
    if(next.signature===this.catalogue.signature)return;
    this.catalogue=next;this.catalogueVersion++;this.bindings=new WeakMap();
  }

  private syncCanopyPresentation(){

    if(key===this.canopyPresentationKey)return;

    if(this.assetDraw)for(const [kind,entry] of this.assets.entries){
      const presentation=entry.family.canopyPresentation;
      if(presentation?.enabled)families.set(kind,presentation);
    }
    const catalogue=this.catalogue;
    this.fullCanopy?.setPresentation?.(key,(id,heightM)=>{
      if(!families.size)return 0;
      const binding=catalogue.resolve(id),kind=forestPresentationFamily(binding,heightM,families);
      return kind&&binding?packForestPresentation(kind,binding.appearance.barkBrightness,binding.appearance.foliageBrightness):0;
    },families);
    this.presentedFamilies=families;
    this.canopyPresentationKey=key;
  }

  private startWorker(){
    try{
      const worker=new Worker(new URL('./planet-population-worker.ts',import.meta.url),{type:'module'});this.worker=worker;
      worker.onmessage=({data})=>{
        if(this.worker!==worker||!this.selecting)return;
        if(!data||!Number.isSafeInteger(data.requestId)){this.failWorker(worker);return;}
        if(data.requestId===this.selectionRequest){
          const started=performance.now();let cells:PopulationCell[];
          try{
            if(!this.selectionDirection||!Number.isFinite(data.selectionMs)||data.selectionMs<0||
              !Number.isFinite(data.packMs)||data.packMs<0)throw new Error('Invalid forest response metadata');
            cells=unpackForestSelection(data.packed);
          }catch{this.failWorker(worker);return;}
          this.selectionTransfer={bytes:data.packed.buffer.byteLength,cells:cells.length,packMs:data.packMs,decodeMs:performance.now()-started};
          // The main thread owns the requested centre; response metadata
          // cannot move it, and duplicate completed replies are ignored.
          // Application errors must surface as main-thread bugs, not use up
          // a worker restart or be silently converted into a fallback.
          this.selectionCacheStats=data.cache??null;this.applySelection(this.selectionDirection!,cells,data.selectionMs);
        }
      };
      worker.onerror=event=>{event.preventDefault();this.failWorker(worker);};
      worker.onmessageerror=()=>this.failWorker(worker);
    }catch{this.worker=null;this.selecting=false;this.workerFailures++;}
  }
  private failWorker(worker:Worker){
    if(this.worker!==worker)return;
    worker.terminate();this.worker=null;this.selectionCacheStats=null;this.selectionTransfer=null;this.selectionDirection=null;this.selecting=false;this.workerFailures++;this.selectionRequest++;
    if(this.workerRestarts<1){this.workerRestarts++;this.startWorker();}
  }

  private writeInstance(batch:number,index:number,resident:Resident,coverage:number){
    const mesh=batch===2?this.canopy:this.meshes[batch],updates=this.updates[batch];
    const changed=updates.residents[index]!==resident;
    if(changed||updates.originVersions[index]!==this.originVersion){
      const {cell,height}=resident,r=this.body.radiusM;
      this.direction.set(...cell.direction);
      this.position.copy(this.direction).multiplyScalar(1+height/r).sub(this.origin);
      treeQuaternion(this.direction,cell.yaw,this.quaternion,this.yaw);
      this.scale.setScalar(cell.heightM/r);
      this.matrix.compose(this.position,this.quaternion,this.scale);mesh.setMatrixAt(index,this.matrix);
      updates.matrix.include(index,16);updates.originVersions[index]=this.originVersion;this.matrixWrites++;
    }
    if(changed){
      const roll=resident.cell.roll;
      this.color.setRGB(.8+roll*.2,.85+roll*.15,.75+roll*.25);mesh.setColorAt(index,this.color);
      updates.color.include(index,3);updates.residents[index]=resident;this.colorWrites++;
      const seed=mesh.geometry.getAttribute('instanceForestSeed') as THREE.InstancedBufferAttribute;seed.setX(index,Math.min(255,Math.floor(roll*256)));updates.seed.include(index,1);
    }
    const detailed=batch<2&&!!this.detailEntry(resident);
    const attribute=batch===2?this.canopyCoverage:this.coverage[batch],value=Math.fround(detailed?0:coverage);
    if(attribute.getX(index)!==value){attribute.setX(index,value);updates.coverage.include(index,1);this.coverageWrites++;}
  }

  private writeDetailed(entry:ForestTreeFamilyEntry<Resident,AssetSlot>,lod:number,index:number,resident:Resident,previous:AssetSlot|undefined):AssetSlot{
    const asset=entry.batches[lod],binding=this.binding(resident)!,cell=resident.cell;
    let state=previous;
    if(!previous||previous.resident!==resident||previous.originVersion!==this.originVersion||previous.catalogueVersion!==this.catalogueVersion){
      this.direction.set(...cell.direction);this.position.copy(this.direction).multiplyScalar(1+resident.height/this.body.radiusM).sub(this.origin);
      treeQuaternion(this.direction,cell.yaw,this.quaternion,this.yaw);
      this.scale.setScalar(1/this.body.radiusM);this.matrix.compose(this.position,this.quaternion,this.scale);
      asset.setInstance(index,this.matrix,cell.heightM,binding.appearance.windPhase01*2*Math.PI);
      const bark=binding.appearance.barkBrightness,leaf=binding.appearance.foliageBrightness;
      asset.setAppearance(index,[bark,bark,bark],[leaf,leaf,leaf]);
      state={resident,originVersion:this.originVersion,catalogueVersion:this.catalogueVersion};
    }
    asset.setCoverage(index,entry.coverage[lod].get(cell.id)!,Math.min(255,Math.floor(cell.roll*256)));
    return state!;
  }
  private wantInstance(batch:number,resident:Resident,coverage:number){

    const updates=this.updates[batch];updates.wanted.push(resident);updates.wantedCoverage.push(coverage);updates.wantedIds.add(resident.cell.id);

  private reconcileBatch(batch:number){
    const updates=this.updates[batch],mesh=batch===2?this.canopy:this.meshes[batch];
    const coverage=batch===2?this.canopyCoverage:this.coverage[batch];
    if(batch<2){
      for(const entry of this.assets.entries.values()){entry.wanted[batch].length=0;entry.coverage[batch].clear();}
      for(let i=0;i<updates.wanted.length;i++){
        const resident=updates.wanted[i],entry=this.detailEntry(resident);if(!entry)continue;
        entry.wanted[batch].push(resident);entry.coverage[batch].set(resident.cell.id,updates.wantedCoverage[i]);
      }
      for(const entry of this.assets.entries.values()){
        const count=entry.pools[batch].reconcile(entry.wanted[batch],(index,resident,previous)=>this.writeDetailed(entry,batch,index,resident,previous));
        entry.batches[batch].setCount(count);entry.batches[batch].group.visible=count>0;
        this.assetCounts[batch]+=count;
      }
    }
    // A departure moves only the final resident into the hole. Reverse traversal
    // ensures that moved residents have already been checked for retention.
    for(let index=updates.residents.length-1;index>=0;index--){
      const resident=updates.residents[index];if(updates.wantedIds.has(resident.cell.id))continue;
      updates.slots.delete(resident.cell.id);
      const last=updates.residents.length-1;
      if(index!==last){
        const moved=updates.residents[last];this.writeInstance(batch,index,moved,coverage.getX(last));
        updates.slots.set(moved.cell.id,index);
      }
      updates.residents.pop();updates.originVersions.pop();
    }
    for(let i=0;i<updates.wanted.length;i++){
      const resident=updates.wanted[i];let index=updates.slots.get(resident.cell.id);
      if(index===undefined){index=updates.residents.length;updates.slots.set(resident.cell.id,index);}
      this.writeInstance(batch,index,resident,updates.wantedCoverage[i]);
    }
    mesh.count=updates.residents.length;
    if(batch<2&&this.assetCounts[batch]===mesh.count)mesh.visible=false;
    this.scheduledUploadBytes+=updates.matrix.flush(mesh.instanceMatrix);
    if(mesh.instanceColor)this.scheduledUploadBytes+=updates.color.flush(mesh.instanceColor);
    this.scheduledUploadBytes+=updates.coverage.flush(coverage);
    this.scheduledUploadBytes+=updates.seed.flush(mesh.geometry.getAttribute('instanceForestSeed') as THREE.BufferAttribute);
  }
  update(eye:THREE.Vector3,groundDirection:V3,altitudeM:number,enabled:boolean,water:number,immersive:boolean,frusta:THREE.Frustum[]=[],worldNs=0n,treeSpecies?:readonly Species[],shadowFrustum:THREE.Frustum|null=null){
    if(!Number.isFinite(water))throw new Error('Forest water level must be finite');
    if(this.assets.entries.size)this.setCatalogue(treeSpecies);
    this.worldDate=worldNs;this.assets.setDate(worldNs);
    this.assetDraw=this.assets.entries.size>0&&!immersive;this.assetCounts=[0,0];
    this.syncCanopyPresentation();
    for(const entry of this.assets.entries.values())for(const batch of entry.batches)batch.group.visible=false;
    const updateStarted=performance.now();
    this.group.visible=enabled&&altitudeM<B.forestStreamAltitudeM;
    this.visibleTrees=0;this.nearTrees=0;this.placementMs=0;this.selectionMs=0;
    this.matrixWrites=0;this.colorWrites=0;this.coverageWrites=0;this.scheduledUploadBytes=0;this.originRebased=false;this.updateMs=0;this.farOwnedSkipped=0;
    if(!this.group.visible){if(this.fullCanopy)this.fullCanopy.group.visible=false;return;}
    const draw=altitudeM<B.forestPrepareAltitudeM;
    for(const mesh of this.meshes)mesh.visible=draw;this.canopy.visible=draw;
    if(!draw){
      this.fullCanopy?.prepare(eye,groundDirection,altitudeM,water,enabled,immersive,this.origin);
      this.fullCanopy?.finish();this.updateMs=performance.now()-updateStarted;return;
    }
    if(immersive!==this.immersiveMaterial){
      this.immersiveMaterial=immersive;
      for(const mesh of [...this.meshes,this.canopy]){const material=mesh.material as THREE.MeshLambertMaterial;material.alphaHash=immersive;material.needsUpdate=true;}
    }
    const hydrologyChanged=this.sampledRivers!==this.body.canonicalRivers||this.sampledHydrology!==this.body.hydrology;
    if(water!==this.water||hydrologyChanged){
      this.sampledRivers=this.body.canonicalRivers;this.sampledHydrology=this.body.hydrology;
      if(hydrologyChanged)for(const resident of this.cache.values())resident.water=NaN;
      this.patchBroadphase.setWater(water);if(hydrologyChanged)this.patchBroadphase.invalidate();
      this.workStateVersion++;
      this.water=water;this.sample=terrainSampler(this.body,undefined,undefined,undefined,water);
      this.classify=biomeClassifier(this.body,water);
      this.habitat=forestHabitat(this.sample,this.classify,this.body.radiusM);
      // Selection depends only on identity/location, not water. Keep the single
      // in-flight job and resident trees while bounded habitat refresh replaces
      // them. Never queue another expensive selection on each playback bucket.
      this.queue=this.wanted.filter(cell=>this.cache.get(cell.id)?.water!==water);
    }
    const r=this.body.radiusM,ground=this.direction.set(...groundDirection);
    if(ground.distanceTo(this.center)*r>40&&!this.selecting){
      if(this.worker){
        const worker=this.worker;this.selecting=true;this.selectionDirection=[...groundDirection];
        try{worker.postMessage({requestId:++this.selectionRequest,seed:this.body.seed,direction:groundDirection,radiusM:r});}
        catch{this.failWorker(worker);}
      }else{
      const started=performance.now();
      const cells=forestPopulationCells(this.body.seed,groundDirection,r,B.forestFootprintM+100,B.canopyFootprintM,B.forestCellM);
      this.applySelection(groundDirection,cells,performance.now()-started);
      }
    }
    const started=performance.now();
    for(let count=0;this.queue.length&&count<B.placementSamplesPerFrame&&performance.now()-started<B.placementBudgetMs;count++){
      const cell=this.queue.shift()!,habitat=this.habitat(cell);
      this.cache.set(cell.id,{cell,height:habitat.groundHeightM,present:habitat.present,water});
      this.patchBroadphase.updateResident(cell.id,{groundHeightM:habitat.groundHeightM,water});
      this.workStateVersion++;
    }
    this.placementMs=performance.now()-started;
    // Retain the anchor across ordinary movement so static tree matrices need
    // no rewrite. Rebase before Float32 conversion to preserve local precision.

function percentile(values: number[], q: number): number {

  values.sort((a, b) => a - b);

function maxNormAtAngle(px: number, py: number, pz: number, ox: number, oy: number, oz: number, s: number, angle: number): number {
  const c = Math.cos(angle), sn = Math.sin(angle);
  const x = px * s + ox * c - oy * sn;
  const y = py * s + ox * sn + oy * c;
  const z = pz * s + oz;

function maxDeformedVertexRadius(px: number, py: number, pz: number, qx: number, qy: number, qz: number,
  leaf: boolean, wind: number): number {
  if (!leaf) return Math.hypot(px, py, pz) * TREE_CANOPY_HEIGHT_RANGE_M[1] / TREE_CANOPY_REFERENCE_HEIGHT_M;
  const ox = px - qx, oy = py - qy, oz = pz - qz, maxAngle = TREE_CANOPY_WIND_MAX_ANGLE_RAD * wind;
  let maximum = 0;
  // For fixed angle, squared distance is convex in uniform skeleton scale, so
  // its maximum over 10..22 m is at an endpoint. Angular maxima occur at the
  // interval ends or where A cos(theta)+B sin(theta) has a stationary point.
  const A = qx * ox + qy * oy, B = -qx * oy + qy * ox;
  const candidates = [-maxAngle, maxAngle];
  const stationary = Math.atan2(B, A);
  for (let k = -2; k <= 2; k++) {
    const a = stationary + k * Math.PI;
    if (a >= -maxAngle && a <= maxAngle) candidates.push(a);
  }

    for (const angle of candidates) maximum = Math.max(maximum, maxNormAtAngle(qx, qy, qz, ox, oy, oz, s, angle));
  }

}

/** Alpha-weighted mean of straight-alpha sRGB RGBA byte pixels, returned in linear RGB. */
export function alphaWeightedLinearRgbMean(rgba: ArrayLike<number>): {linearRgb: [number, number, number]; alphaWeight: number; pixelCount: number} {
  if (!rgba || !Number.isSafeInteger(rgba.length) || rgba.length === 0 || rgba.length % 4 !== 0) throw new Error('Expected non-empty straight sRGB RGBA pixels');
  let weight = 0, r = 0, g = 0, b = 0;
  const byteArray = rgba instanceof Uint8Array || rgba instanceof Uint8ClampedArray;
  for (let i = 0; i < rgba.length; i += 4) {
    const red = rgba[i], green = rgba[i + 1], blue = rgba[i + 2], alpha = rgba[i + 3];
    if (!byteArray && (!Number.isInteger(red) || red < 0 || red > 255 || !Number.isInteger(green) || green < 0 || green > 255 ||
      !Number.isInteger(blue) || blue < 0 || blue > 255 || !Number.isInteger(alpha) || alpha < 0 || alpha > 255)) throw new Error('RGBA values must be integer bytes');
    const a = alpha / 255;
    weight += a; r += srgbLinearLut[red] * a; g += srgbLinearLut[green] * a; b += srgbLinearLut[blue] * a;
  }
  if (weight <= 0) throw new Error('RGBA pixels have no alpha weight');
  return {linearRgb: [r / weight, g / weight, b / weight], alphaWeight: weight, pixelCount: rgba.length / 4};
}

          },

        };
      },
      dispose(){if(disposed)return;if(activeBatches)throw new Error('Dispose tree batches before their family');disposed=true;dispose();},
    };
  }catch(error){dispose();throw error;}
