# Review: opt-in thin-leaf diffuse transmission (source-only)

**Verdict:** The shader patch is structurally sound. The anchors are unique, the globals are declared before use, and the hemisphere logic is right under `DoubleSide`. The main defects are in the **lab fixtures**, which miss the failure modes most likely to show up on real trees. There is also one **design decision (normal-mapped cosine)** to settle before GPU sign-off.

## What I checked and found correct

- **Order.** Declarations replace the `lights_physical_pars_fragment` include, so the uniforms and globals come before `RE_*`. `vec3(0.0)` is a legal constant initializer for a global. The back irradiances are assigned after `lights_fragment_begin` and `lights_fragment_maps` and before `lights_fragment_end`, which is the only place the indirect REs run.
- **Anchors.** All four chunk anchors are distinct and live, so `replaceLiveOnce` fails loudly on drift. The hemi loop matches Three's unroll regex (`i ++`) and is resolved after `NUM_HEMI_LIGHTS` substitution.
- **Hemisphere.** `geometryNormal` has already been flipped by `faceDirection`. So `-geometryNormal` always points to the side away from the viewer, for front and back views alike. For tangent-space normal maps, the back face's perturbed normal is exactly the negated front one, because both `tbn` columns and `normal` are flipped.
- **Area LTC basis.** With `-N`, `T1` is unchanged and `T2` flips, so the basis is `(T1, −T2, −N)`. Its determinant equals the host's, so handedness and winding sign are preserved. With `mInv = I`, the diffuse result is rotation-invariant about the axis, so the basis is correct.
- **Cache key.** Capturing `baseKey` before the wrapper replaces the default key correctly avoids self-describing wrapper text. Per-material `onBeforeCompile` still runs on shared programs, so each material gets its own uniform objects.
- **Energy.** `(1−f)·cosF + f·t·cosB`, with `t ≤ 1`, never exceeds the host's two-sided Lambert. Specular, multiscatter and sheen inputs are untouched.

## Must-fix

1. **Normal-mapped transmission leaks light from the wrong geometric side (design decision).** `dot(-N_perturbed, L)` can be positive for a light on the *viewed* side when the perturbation tilts away at grazing angles. The front-lit face then gains "transmission" and loses `(1−f)` of its reflection. The host already shows this leak for reflection; this patch adds a second copy of it.
   - For thin leaves, I recommend computing the transmission cosine (and the back probe, hemi and IBL lookups) from the **geometric** normal (`nonPerturbedNormal`).
   - Caveat: the direct-light loops run *inside* `lights_fragment_begin`. A global set in your current post-begin hook would be too late for them. Assign it in a hook *before* `#include <lights_fragment_begin>`, after `normal_fragment_maps`.
   - If you keep the shading normal, record that as an explicit limitation, together with the grazing test below.

2. **The "T0 pixel-identical" claim is stronger than the mechanism can guarantee.** `plain` and `adapted` compile to different programs. On ANGLE/D3D in particular, uniform branches can be flattened and FMA contraction can differ.
   - Make the T0 gate a measured `max|Δ|` over all pixels. Expect 0 on your GPU, but set a documented tolerance, for example `1e-6` relative.
   - Report exact identity only when you actually observe it.

3. **The LTC singular point sits inside your probe window.** With `x = .02` at distance 4, the foot of the perpendicular (V ∥ N) projects to about 2 px from center, inside the 120–136 window. The host's `T1 = normalize(V − N(V·N))` loses orthogonality there to cancellation. This is **inherited**: `−N` has the same singular set. The patch evaluates it twice but does not introduce it.
   - For area tests, offset the camera about 0.6 so the point leaves the window.
   - Also report per-pixel outliers, not just the window mean and `finite`.

4. **Self-shadowing on the backlit side is untested and newly exposed.**
   - Tree foliage has `castShadow = true`. The lab leaf does not cast.
   - Previously, a face turned away from the light got `dotNL = 0`, which hid shadow acne and terminator artifacts from comparing the leaf against its own depth.
   - Transmission now lights exactly those fragments.
   - Add a variant with `leaf.castShadow = true`. Backlit transmission at `f = 1` should match the non-casting leaf within tolerance. Tune `bias` and `normalBias` there; normal bias along a normal that faces away from the light pushes deeper into self-shadow.

5. **"Specular preserved" is untested.** The default `specular: 0` gives F0 = F90 = 0.
   - Add a base-color option.
   - Test: base color black, `specular = 1`, directional light and environment, any `f`/`tint`. The adapted render must equal the plain render.

6. **Integration traps for the first tree.** These are not bugs in the current module, but they will bite on first use:
   - glTF `metallicFactor` defaults to **1**.
   - A `metallicRoughnessTexture` becomes `metalnessMap`.
   - `doubleSided` defaults to false.

   Any of these makes `installLeafTransmission` throw. Check the author-6 foliage JSON for all three. Separately, `deform()` overwrites `onBeforeCompile` and the cache key without chaining. If it is ever re-run after install, transmission disappears silently while the WeakSet still reports it installed. Return an `assertInstalled()` from the control that checks `material.onBeforeCompile === wrapper`.

**Minor:** throwing from `onBeforeCompile` breaks the frame loop mid-render. That is acceptable as a loud guard, but document it. The compile-time `metalness !== 0` check is unnecessary, since `diffuseColor` already scales by `1 − metalness`, but it is harmless.

## Explicit limits (document, don't fix)

| Behavior | Inherited or new |
|---|---|
| LTC V∥N singularity; horizon-clip approximation | Inherited, now evaluated twice |
| Rect-area lights unshadowed, so transmission shines through blockers | Inherited; more visible through canopies |
| Env diffuse scaled by front-view `1 − max(scatter)` while direct diffuse is not | Inherited inconsistency, now applied to transmitted light |
| Opaque shadow maps give zero leaf-to-leaf transmission, so only outer-canopy leaves glow | Inherent to this approach |
| `aoMap` (front-hemisphere AO) multiplies transmitted indirect light | New effect of the patch; reject `aoMap` or document |

## Is baseColor × tint a reasonable first experiment?

Yes, provided you track two caveats:

- **Brightness and hue range.** Because `tint ≤ 1`, transmitted light can never be brighter or more saturated than reflected light. You can still make it yellower, for example `(1, 1, .6)`. The backlit glow of real leaves comes mostly from the light's intensity, not the transmittance, so this is fine for a first pass.
- **Baked texture content.** Any baked AO or highlights in the albedo texture also appear in transmission.

Also note that `f` removes front reflectance. Sweeps over `f` therefore darken front-lit leaves, so compare looks at matched front-lit brightness. Start around `f = 0.3–0.5`.

## Small runtime checks with the highest catch rate

1. **Opposite-face identity (hemisphere and normal maps).** At `f = 1`, `tint = 1`, `specular = 0`, the adapted front view should equal the plain back view (center mean) for every light type, with and without `normalMap`. This holds because the back face's shading normal is exactly `−N_front`. With #1 applied, extend this to the geometric-normal variant.
2. **Wrong-side zero.** At `f = 1`, a front light with the front view gives direct diffuse of 0.
3. **Grazing leak.** Use `normalMap`, a front light, `angle` around 75–85°, and `f = 1`. Expect transmission ≈ 0. This test fails today by design; it documents #1.
4. **Zero-factor continuity.** The result at `f = 1e-6` should be within about 1e-5 of the result at `f = 0`. This catches bugs that exist only inside the `> 0` branch. Also include the T0 `max|Δ|` check against `plain`.
5. **Blocker.** With a back light, `blocker` on and `f = 1`, the shadowed center should fall to the shadowed level for directional, point and spot lights. For area lights, expect and record the leak.
6. **Self-shadow.** The `castShadow` leaf variant from #4.
7. **Specular identity.** The black-base-color check from #5.

Each of these is one or two `probe()` calls plus a comparison. None of them requires new infrastructure.

import * as THREE from 'three';
import {liveGlsl} from './tree-impostor-reference-shader.ts';

/** Experimental thin, two-sided leaf response. Uses the sampled base colour
 * times a linear tint for transmission: a bounded subset inspired by Khronos
 * diffuse transmission, not a KHR_materials_diffuse_transmission importer.
 * The host's specular/Fresnel calculations are retained verbatim. */
export type LeafTransmissionOptions={factor?:number;tint?:readonly [number,number,number]};
const VERSION='atlas-leaf-diffuse-1';
const installed=new WeakSet<THREE.Material>();

function replaceLiveOnce(source:string,anchor:string,replacement:string){
  const live=liveGlsl(source),at=live.indexOf(anchor);
  if(at<0||live.indexOf(anchor,at+anchor.length)>=0)throw new Error(`Leaf transmission shader hook changed: ${anchor}`);
  return source.slice(0,at)+replacement+source.slice(at+anchor.length);
}

const declarations=`
uniform float atlasLeafTransmission;
uniform vec3 atlasLeafTransmissionTint;
vec3 atlasLeafBackIrradiance = vec3(0.0);
vec3 atlasLeafBackIblIrradiance = vec3(0.0);
vec3 atlasLeafGeometricNormal = vec3(0.0);
`;

// Branch on a shared uniform so factor zero executes the exact original
// diffuse expression and does not sample opposite-hemisphere environment maps.
function split(original:string,expression:string){
  return `if (atlasLeafTransmission > 0.0) {\n${expression}\n} else {\n${original}\n}`;
}

/** Exported for source-contract tests. Does not mutate global ShaderChunk. */
export function patchLeafTransmissionShader(fragmentShader:string,physicalChunk=THREE.ShaderChunk.lights_physical_pars_fragment){
  if(liveGlsl(fragmentShader).includes('atlasLeafTransmission'))throw new Error('Leaf transmission is already installed');
  let chunk=physicalChunk;
  const direct='reflectedLight.directDiffuse += irradiance * BRDF_Lambert( material.diffuseColor );';
  chunk=replaceLiveOnce(chunk,direct,split(direct,`
    vec3 backIrradiance = saturate(dot(-atlasLeafGeometricNormal, directLight.direction)) * directLight.color;
    reflectedLight.directDiffuse += ((1.0-atlasLeafTransmission)*irradiance
      + atlasLeafTransmission*atlasLeafTransmissionTint*backIrradiance) * BRDF_Lambert(material.diffuseColor);`));

  const area='reflectedLight.directDiffuse += lightColor * material.diffuseColor * LTC_Evaluate( normal, viewDir, position, mat3( 1.0 ), rectCoords );';
  chunk=replaceLiveOnce(chunk,area,split(area,`
    reflectedLight.directDiffuse += lightColor * material.diffuseColor * (
      (1.0-atlasLeafTransmission)*LTC_Evaluate(normal, viewDir, position, mat3(1.0), rectCoords)
      + atlasLeafTransmission*atlasLeafTransmissionTint*LTC_Evaluate(-atlasLeafGeometricNormal, viewDir, position, mat3(1.0), rectCoords));`));

  const indirect='reflectedLight.indirectDiffuse += irradiance * BRDF_Lambert( material.diffuseColor );';
  chunk=replaceLiveOnce(chunk,indirect,split(indirect,`
    reflectedLight.indirectDiffuse += ((1.0-atlasLeafTransmission)*irradiance
      + atlasLeafTransmission*atlasLeafTransmissionTint*atlasLeafBackIrradiance) * BRDF_Lambert(material.diffuseColor);`));

  const environment='reflectedLight.indirectDiffuse += diffuse * cosineWeightedIrradiance;';
  chunk=replaceLiveOnce(chunk,environment,split(environment,`
    reflectedLight.indirectDiffuse += diffuse * ((1.0-atlasLeafTransmission)*cosineWeightedIrradiance
      + atlasLeafTransmission*atlasLeafTransmissionTint*atlasLeafBackIblIrradiance*RECIPROCAL_PI);`));
  let shader=replaceLiveOnce(fragmentShader,'#include <lights_physical_pars_fragment>',declarations+chunk);
  shader=replaceLiveOnce(shader,'#include <lights_fragment_begin>',`
    // nonPerturbedNormal already includes vertex wind and DoubleSide flipping.
    // Transmission follows the thin surface, not bumps that can cross its side.
    atlasLeafGeometricNormal = nonPerturbedNormal;
    #include <lights_fragment_begin>
    if (atlasLeafTransmission > 0.0) {
      atlasLeafBackIrradiance = getAmbientLightIrradiance(ambientLightColor);
      #ifdef USE_LIGHT_PROBES
        atlasLeafBackIrradiance += getLightProbeIrradiance(lightProbe, -atlasLeafGeometricNormal);
      #endif
      #if NUM_HEMI_LIGHTS > 0
        #pragma unroll_loop_start
        for ( int i = 0; i < NUM_HEMI_LIGHTS; i ++ ) {
          atlasLeafBackIrradiance += getHemisphereLightIrradiance(hemisphereLights[ i ], -atlasLeafGeometricNormal);
        }
        #pragma unroll_loop_end
      #endif
    }`);
  shader=replaceLiveOnce(shader,'#include <lights_fragment_maps>',`#include <lights_fragment_maps>
    #if defined(USE_ENVMAP) && defined(STANDARD) && defined(ENVMAP_TYPE_CUBE_UV)
      if (atlasLeafTransmission > 0.0) {
        atlasLeafBackIblIrradiance = getIBLIrradiance(-atlasLeafGeometricNormal);
      }
    #endif`);
  // Both opposite irradiances must exist before the host calls its indirect REs.
  const live=liveGlsl(shader),end=live.indexOf('#include <lights_fragment_end>');
  if(end<0||live.indexOf('#include <lights_fragment_end>',end+1)>=0||end<live.lastIndexOf('atlasLeafBackIblIrradiance = getIBLIrradiance'))throw new Error('Leaf transmission indirect-light order changed');
  const normals=live.indexOf('#include <normal_fragment_maps>'),begin=live.indexOf('#include <lights_fragment_begin>'),maps=live.indexOf('#include <lights_fragment_maps>');
  if(normals<0||live.indexOf('#include <normal_fragment_maps>',normals+1)>=0||normals>begin||begin>maps||maps>end)throw new Error('Leaf transmission normal/light order changed');
  return shader;
}

function values(options:LeafTransmissionOptions){
  const factor=options.factor??0,tint=options.tint??[1,1,1];
  if(!Number.isFinite(factor)||factor<0||factor>1||!Array.isArray(tint)||tint.length!==3||tint.some(x=>!Number.isFinite(x)||x<0||x>1))throw new Error('Leaf transmission factor and linear tint must be in [0,1]');
  return {factor,tint:tint as readonly [number,number,number]};
}

function validateMaterial(material:THREE.MeshStandardMaterial){
  const physical=material as THREE.MeshPhysicalMaterial;
  if(!material.isMeshStandardMaterial||material.side!==THREE.DoubleSide||material.metalness!==0||material.metalnessMap||material.lightMap||material.aoMap||(physical.transmission??0)!==0||physical.transmissionMap)throw new Error('Leaf transmission requires a two-sided dielectric without metalness maps, lightmaps, AO maps or glass transmission');
}

/** Call AFTER the wind/deformation adapter. Shared uniforms work for all
 * instances and LODs; depth/distance materials are deliberately not changed.
 * Material flags affecting the supported domain must remain valid at compile.
 * Reapply explicitly if a material is cloned (Three does not clone hooks). */
export function installLeafTransmission(material:THREE.MeshStandardMaterial,options:LeafTransmissionOptions={}){
  const initial=values(options);validateMaterial(material);
  if(installed.has(material))throw new Error('Leaf transmission is already installed on this material');
  const factor={value:initial.factor},tint={value:new THREE.Vector3(...initial.tint)};
  const previousCompile=material.onBeforeCompile;
  // Capture the default key before installing our wrapper: Three's default key
  // reads this.onBeforeCompile and would otherwise describe the wrapper itself.
  const previousKey=material.customProgramCacheKey.bind(material);
  const baseKey=previousKey();
  const defaultKey=material.customProgramCacheKey===THREE.Material.prototype.customProgramCacheKey;
  const compile:THREE.Material['onBeforeCompile']=function(this:THREE.Material,shader,renderer){
    validateMaterial(material);
    previousCompile.call(this,shader,renderer);
    const patched=patchLeafTransmissionShader(shader.fragmentShader);
    if(shader.uniforms.atlasLeafTransmission||shader.uniforms.atlasLeafTransmissionTint)throw new Error('Leaf transmission uniform collision');
    shader.uniforms.atlasLeafTransmission=factor;
    shader.uniforms.atlasLeafTransmissionTint=tint;
    shader.fragmentShader=patched;
  };
  const key=()=>`${defaultKey?baseKey:previousKey()}|${VERSION}`;
  material.onBeforeCompile=compile;material.customProgramCacheKey=key;
  installed.add(material);material.needsUpdate=true;
  return {
    assertInstalled(){if(material.onBeforeCompile!==compile||material.customProgramCacheKey!==key)throw new Error('Leaf transmission hook was replaced after installation');},
    /** Values update atomically; no material/program per tree or per setting. */
    set(options:LeafTransmissionOptions){const next=values(options);factor.value=next.factor;tint.value.set(...next.tint);},
    get factor(){return factor.value;},
    get tint():readonly [number,number,number]{return [tint.value.x,tint.value.y,tint.value.z];},
  };
}

/** CPU reference for shader audits. Scale skeleton/attachment coordinates,
 * keeping every offset within a leaf card in metres, then rotate rigidly. */
export function treeVertexMeters(position:THREE.Vector3,pivot:THREE.Vector3,leaf:boolean,heightM:number,windWeight:number,phase:number,instancePhase=0){
  if(!Number.isFinite(heightM)||heightM<10||heightM>22)throw new Error('Prototype supports tree heights 10–22 m');
  if(!leaf)return position.clone().multiplyScalar(heightM/TREE_REFERENCE_HEIGHT_M);
  return position.clone().sub(pivot).applyAxisAngle(new THREE.Vector3(0,0,1),Math.sin(phase+instancePhase)*.12*windWeight).addScaledVector(pivot,heightM/TREE_REFERENCE_HEIGHT_M);
}

const declarations=`
attribute float _wind, _branch_level;
attribute vec3 _leaf_pivot;
attribute vec2 instanceTree;
uniform float atlasTreePhase;
mat3 atlasLeafRotation(){
  float angle=sin(atlasTreePhase+instanceTree.y)*.12*_wind;
  float c=cos(angle),s=sin(angle);
  return mat3(c,s,0.,-s,c,0.,0.,0.,1.);
}
`;
function deform(material:THREE.Material,phase:{value:number}){
  material.onBeforeCompile=shader=>{
    shader.uniforms.atlasTreePhase=phase;
    shader.vertexShader=declarations+shader.vertexShader;
    shader.vertexShader=shader.vertexShader.replace('#include <beginnormal_vertex>',`#include <beginnormal_vertex>
      if(_branch_level>3.5){objectNormal=atlasLeafRotation()*objectNormal;
        #ifdef USE_TANGENT
        objectTangent=atlasLeafRotation()*objectTangent;
        #endif
      }`);
    shader.vertexShader=shader.vertexShader.replace('#include <begin_vertex>',`#include <begin_vertex>
      transformed=_branch_level>3.5 ? _leaf_pivot*instanceTree.x+atlasLeafRotation()*(position-_leaf_pivot) : position*instanceTree.x;`);
  };
  material.customProgramCacheKey=()=> 'atlas-tree-physical-1';
}
