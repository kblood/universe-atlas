## The problem

With the mountains wired (`TERRAIN_MOUNTAINS_WIRED`, staged false on main; samplers opt in with `{mountains: true}`)
the core terrain sample costs +17..+33% per coarse tile level and +19..+27% per orbit bake, although no M3 block is
solved there. Land samples OUTSIDE every belt pay +40% while doing no mountain work (massifBeltSample returns belt 0
from the band grid). Making the M1 call dead removes most of the excess. Diagnosis: the live M1 call inside the ONE
shared `baseTerrainCore` `sample` closure degrades V8's code for it (macroHeightCode / n no longer inlined; core
`sample` self time 1,535 ms mountains-on vs 641 ms off). Restructurings INSIDE that one function all failed.
