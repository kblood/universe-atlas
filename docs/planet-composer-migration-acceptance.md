# Planet Composer migration acceptance

Baseline: Atlas `f56fc9311bcd3c69c1341842a496a713584bee3f`. Verification branch contains tests and evidence only; production source belongs to the implementing agents. Startup is read-only: no browser, corpus generation or performance run until the coordinator provides a frozen build, new public definition/pose API, renderer hooks and approved numeric budget pins.

## Concrete gates

1. **Automatic airborne entry (HARD).** Ordinary Animal Finder → Visit → Find living habitat renders Composer without an experiment query, manual recipe selection, landing or walking prerequisite. Capture actual main-camera draw callbacks and visible-versus-hidden fauna pixels after current meshes are built; stale pre-build callbacks are not proof.
2. **One source with the Lab (HARD).** Import a runtime individual definition into the advanced Lab. Recipe, complete resolved phenotype/source genome/coat/metres, source IDs, stage, presentation and graph/skin/pose versions remain unchanged. Build independently through the pinned public Kit API and compare actual source buffers, bone names/count, skin influences and palette stride. Recipe-only links are insufficient for `planet-composer-definition-1`. Metadata/source hashes identify data, not visual quality.
3. **Same-source LOD and fallback (HARD + CONTRACT).** Worker, near, reduced and temporary fallback representations originate from that Composer source. Reject wrong recipe/style/version/borrowed quadruped payload before transfer. Validate decoded packed output, skinning and protected feet/head/trunk at intended scales. Reaching a triangle target alone never approves a tier. A budget refusal must not silently substitute the old quadruped generator.
4. **Population and date preservation (HARD).** At matched seed/body/date/camera compare resident canonical census IDs, species/member seeds, variants/stages, anchor data, dated positions and activity. Compare resident census separately from the visible draw list: new body bounds can legitimately alter visibility. Observer movement, geometry readiness, source/LOD transitions and revisits must not reseed individuals.
5. **Growth applied once (HARD + CONTRACT).** Verify species-level data and individual/growth application separately. Legacy runtime phenotypes are already individualized; the adapter must not apply seed variation or young scaling twice. Review actual adult/young dimensions against coordinator-approved growth pins rather than accepting a `stage` label.
6. **Real gait and nonflat ground (HARD + CONTRACT).** Walking has finite `revolutionS`, actual changing foot poses and both stance and swing. Sample deformed production mesh sole vertices against the real nonflat ground callback/stencil in local metres. Solver contact markers alone do not prove soles are grounded. Include a mild ramp, a non-affine patch and the actual habitat ground; use owner-pinned penetration/gap limits.
7. **Deterministic seeks (HARD).** Pause and run A → B → A, reverse seeks, gait transition boundaries and a rebase/large-date case. The same IDs/definitions and dated root/rig poses recur; scene changes cannot depend on wall clock or camera movement. Include true activity `revolutionS`, `stateS`, travel and rig clock in receipts.
8. **Complete ownership (HARD).** For every submitted canonical ID, near/LOD/fallback intervals partition `[0,1)` without holes or double coverage. Audit camera/shadow distinctions and range fades. Pair the interval audit with actual current main-camera drawing and a fixed-date pixel mask check.
9. **Caches and lifecycle (HARD + CONTRACT).** Exercise cold build/adopt, cancellation, stale result delivery, renderer/session disposal and A → B → A planet revisits. Borrowed input stays attached/unchanged; at most the approved worker concurrency exists; terminated/cancelled workers cannot adopt old results. Typed buffers, source copies, bone/attribute textures, cache residency and transient/peak scopes are measured and bounded. Repeated-visit residency must reach a pinned plateau; no invented JS/GPU heap totals.
10. **Desktop and XR remain Composer (HARD).** Simulated renderer/session transition tests must not restore `quadruped-body-*` or its 22-bone transport. Verify actual variable graph names/counts/JOINT range/palette stride. A physical headset run is distinct from emulation; do not claim device acceptance from the desktop lifecycle test.
11. **Whole-runtime budget and quality (CONTRACT).** Coordinator supplies numeric actor, bone, geometry, frame-triangle/draw, resident/worker/transport/GPU-allocation and device/frame-time limits. Measure a serialized representative desktop/XR window only after functional correctness. Per-asset 8000/3000/1000 export success is not a planet scene budget. Never loosen pins to obtain a pass.
12. **Supported scope is explicit (HARD).** Historical planet population has four clades. Renderer support for arbitrary recipes or a TypeScript union does not prove the procedural fauna definition generates snakes, insects or other layouts. Report generated/approved layouts from actual definitions; add new-layout acceptance only when the new versioned population definition actually supports them.

## Required hooks / owner decisions

Provide immutable individual definitions; actual source graph/skin/pose versions and bone data; actual bound mesh/packed geometry and palette samples; full dated activity; real ground samples; current source/LOD/fallback ownership and draw objects; exact resident census; scoped allocation/cache/worker counters; and a session-transition/dispose test surface. Supply a separately approved policy manifest with numeric pins. Missing hooks/pins report **NOT RUN / BLOCKED**, never a synthetic pass.

Keep source-byte parity, independent numerical/contract checks, visual findings and device/performance conclusions separate. Preserve the original controls, candidate inputs, seeds, prompts, versions and license/provenance. No main/source edits or source/golden repins by this verifier.
